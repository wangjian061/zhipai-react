# 制作前检测、返回与失败抽屉检查

日期：2026-10-20。范围：个人证件照制作与专项拍摄共用流程；视觉依据 Impeccable 及用户确认方案。当前为本地实现，未提交或发布。

## 已完成

1. 「开始制作」先进入照片检测上滑抽屉。默认检查有人像、单人、无动物；仅执行启用项，缺失或无效配置阻止制作。检测通过自动继续；拒绝显示实际原因；异常可重新检测。
2. 检测可取消，异步结果绑定当前任务。更换原图或策略、取消及制作失败使旧证明失效；制作入口只接受本次检测通过状态，不通过不能进入制作、结果或收费流程。
3. 确认页顶部返回退出制作回到调用页面；底部「重新拍摄」才进入临时重拍，取消恢复原图与参数。初始相机返回退出到来源；规范化返回地址，避免相机与确认页循环。专项成功回传保持原契约。
4. 制作失败与检测失败复用白色上滑抽屉，原因直接展示，固定头部与操作区、正文滚动；「返回调整」保留有效输入。制作仍为约5秒不可取消Loading，再选择演示成功／失败。
5. 「重新选择／重新拍摄」采用灰色文字与描边，主操作保留知拍蓝。既有预览比例、参数区、只读成片与交易保护保持。

## 实施文件

- `src/domain/camera-detection.js`：配置契约、模拟结果、配置校验与安全返回地址。
- `src/domain/camera.js`：检测门禁、取消／刷新恢复、失败处理与返回状态。
- `src/components/CameraTaskSheet.jsx`、`src/styles/camera-task-sheet.css`：检测与失败共用抽屉。
- `src/components/CameraWorkflow.jsx`、`src/pages/CameraPage.jsx`、`src/styles/camera-workflow.css`：移除旧居中失败提示、接入抽屉与弱化次操作。
- `public/camera-workflow-test.html`：通过、动物、多人、无人像及检测异常的原型测试入口。

## 原型边界与待验收

- 检测配置是本地数据契约，未建设后台配置界面；场景结果为模拟，不执行真实人像、人数或动物识别。
- 制作、结果选择及付款为演示，不代表真实AI处理或资金交易。相机权限与实际移动浏览器需真机验收。
- 遵守用户约定，未操作浏览器、截图或运行自动UI测试。待用户确认实际抽屉高度、触摸滚动、长原因、横竖照片、焦点／读屏和返回行为。
- 本记录的专用测试入口已于2026-10-20被流程内场景选择弹窗取代并删除。当前直接在证件照制作页点击「开始制作」演示，最新规则见[场景弹窗检查](../camera-scenario-modal-20261020/review.md)。
