# 配置式检测提示 · 删除定向指导

日期：2026-10-20。用户根据实际截图确认：检测项由后台配置，删除前端按演示场景拼出的额外指导，代码与文档同步修改。视觉沿用 Impeccable 与现有失败抽屉。

## 当前规则

检测未通过只保留以下内容：

1. 标题「检测未通过」。
2. 统一说明「当前照片不符合制作要求，暂时无法开始制作。」。
3. 本次原图及「原照片和设置已保留。」。
4. 按配置展示的检测项名称及结果。
5. 固定蓝色「返回调整」。

前端不根据无人像、多人或动物场景生成额外定向提示，不展示额外原因段，不增加缺少原因的兜底文案。旧草稿中保存的定向原因也不展示、不加入可访问描述。删除该段后收掉原有段落间距，避免残留空白。

照片制作失败、制作服务不可用及检测服务异常继续展示各自实际原因。检测门禁、通过自动继续、取消、重试、原图及参数保留的规则保持。

当前仍为本地配置和模拟检测。正式对接以后台配置与返回数据为准；本轮未增加后台配置页面、真实识别或新检测项类型。
