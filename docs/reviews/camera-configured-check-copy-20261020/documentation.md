## 文案与状态对齐

检测拒绝保留标题「检测未通过」及说明「当前照片不符合制作要求，暂时无法开始制作。」；随后显示原图、「原照片和设置已保留。」及检测明细，底部为蓝色「返回调整」。不生成或显示额外定向原因，不使用通用原因替代；业务旧草稿中的定向原因也不再展示或加入可访问描述。

线框在`makingFailure`分支中才创建原因节点；进入检测拒绝时移除旧节点，ARIA只引用统一说明。说明成为结果区最后一段时，下方不残留原原因前的12px间距。照片制作失败、制作服务不可用及检测服务异常继续显示各自实际原因，既有返回、重新检测、通过自动继续和未通过阻止制作的规则保持。

检测项由后台配置属于产品契约；当前原型仍为本地配置与已知场景模拟，默认三项只用于演示。本轮没有建设后台、接入真实识别或扩展原型支持的检测项类型。HTML沿用内存状态，不存储业务草稿、照片、交易或订单，刷新只重置文档。

本轮未将内部视觉方向契约复制到浏览器交付内容，未生成位图，未修改视觉sidecar，也未覆盖其他已有改动。
