## 实现

- 第二步「AI精修」改为「照片精修」，付款标题「开始照片精修」，旧工具订单视图标题统一为照片精修订单。
- 当前照片下增加`RepairBackgroundOptions`：蓝、白、红、浅灰四个原生单选，初始全未选；32px色块、12px名称、至少44px触控、选中蓝圈及勾选、可见键盘焦点。组标题回显「请选择一种／已选：白色」。未选禁用主操作，同时在付款及处理入口做校验。
- `repairBackgroundId`与独立换背景工具的默认值隔离。选择时不制作底色预览，不创建订单，不改原图；仅待付款及处理确认后生成本次成片。
- 首次付款将`repairBackground: {id,name,value}`和`purchaseSnapshot.backgroundName`写入原订单；取消或明确未付可改色，重新提交更新原pending单，复用ID。待确认／已付后锁定；处理从原单读取照片及底色，完成摘要及只读订单凭据显示本单颜色。
- 已付处理失败保留原参数和付款权益；保存失败复用产物，稳定相册ID防止重复归档。修复首付并发提交在进入busy之前的异步空隙，避免重复建单及异常反馈。
- 相同照片回退或重新确认保留底色；确认另一张照片、重新开始清空选择并重新检查。历史已付单无底色字段时按原处理契约及文件恢复，设置区回显「沿用原订单」，不推断默认蓝色或修改旧成片。
- 本地处理仍为滤镜及已有简单边缘连通背景替换模拟，不代表真实AI。新选色在实际输出中执行，原图和像素尺寸保留，仍输出JPEG。PRODUCT、DESIGN、HANDOFF、工具产品文档及结构说明同步。
