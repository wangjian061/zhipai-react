# 证件照制作失败视觉修订

日期：2026-10-19。范围：个人照片确认页的失败状态及失败原因抽屉；采用 oil-ui-pro 既有项目精修路径，沿用 DESIGN.md。已实现，实际视觉与触摸待用户验收。

## 已确认方案

用户保留失败状态在照片下方，否定将状态移到照片上方；要求失败时隐藏照片下方的重新拍摄入口。规格收为可展开摘要，底部只保留重新制作。重新制作沿用既有语义，使用当前照片与最新规格重试，不重新拍摄或选图。

## 实现

- 原图下方集中展示24px失败图标、18px加粗失败标题与13px灰色描述；图标在标题、描述组合左侧，状态使用项目失败红。未增加失败背景、插画、照片卡片或遮罩。
- 删除失败时换图入口及长说明，改为「原照片已保留」。只有「查看失败原因」进入原因抽屉，不在主页面重复原因全文。
- 个人制作规格默认折叠；摘要显示当前尺寸与底色，自定义显示精确像素。使用原生details支持展开、收起和键盘操作，沿用已有设置及更多尺寸抽屉。专项采集仍只显示固定规格说明。
- 原因抽屉保留统一固定头部、独立滚动正文和底栏，实际原因与处理方式以留白分区。额外备份错误保留独立可见提示。
- 未改业务状态与支付流程。正常确认保留来源换图，处理中仍禁用交互，成功进入既有结果页。
- 同步DESIGN.md、照片确认产品文档及HTML交互式结构说明。

## 实际验收

遵守项目不自动操作浏览器、截图的约定，本轮未取得实际画面证据、未独立视觉评审，不提供视觉评分。没有新增流程动效：保留原照片处理扫描和上滑抽屉，规格摘要箭头160ms旋转，减少动态效果时关闭过渡。

用户在402×874及窄屏验收：制作后选择失败，确认状态在照片下方、没有换图；打开原因抽屉检查长原因滚动与关闭；展开规格修改再制作，确认使用同一照片及最新规格；再次失败与成功各走一遍。检查图标与两行文字对齐、底部按钮和安全区、焦点返回及展开后最后一项可滚动到达。
