## 本轮变化

- 状态标签13px、计数11px；类型从横滑标签改为单行入口及三列两行公共抽屉，当前交集数量可见。
- 卡片沿用16px白卡、真实56×78px照片和既有配色。名称最多两行，摘要精简为已记录规格及必要服装；日期和金额对齐，详情保留完整参数。
- 详情分为交易概览、购买内容、冲印独立费用、必要配送、订单凭据；已支付／已关闭没有固定底栏。
- 长编号折叠并就地展开，复制始终取完整值；照片仍不可点击，不新增客服、照片或业务操作。
- 五类订单共用付款／查询抽屉；冲印继续付款接入原单交易适配器，保留原冲印费用校验、付款后履约状态和草稿完成标记。冲印取消使用居中确认，只关闭原pending单。
- 新电子订单增加制作规格、文件尺寸和底色快照；工具记录实际输入规格。历史缺失参数不由价格／像素补造，不改变旧ID、金额或文件。
- 切换筛选回顶，详情返回保留筛选与滚动；页面返回不新增重复导航记录，覆盖层先关闭、忙碌交易不允许中断。
- 更新PRODUCT、DESIGN、HANDOFF、常用工具文档／线框及README；新增订单独立产品契约和复用实际组件的隔离交互样例。
