## 已对齐的流程

1. 点击「开始制作」打开「选择演示场景」，说明「原型演示，请选择本次照片检测情况。」。
2. 按当前 `CAMERA_DETECTION_SCENARIOS` 顺序显示「检测通过／无人像／多人照片／动物照片／检测异常」。无预选，点击选项后才进行约1.8秒检测。
3. 取消、遮罩或Escape关闭选择，不启动检测，保留原照片、尺寸及底色；业务浏览器返回同样关闭选择并恢复确认。
4. 检测通过后自动进入约5秒制作Loading，结束后仍必须选择「制作失败／制作成功」；制作及制作结果选择不可取消。
5. 检测异常的「重新检测」再次打开场景选择，可选择不同情况；取消恢复确认。拒绝、异常与制作失败沿用现有原因抽屉。

场景选择沿用300px宽、16px圆角弹窗，18px标题、15px正文与纵向选项；选项至少44px高，内容可滚动，灰色取消固定在底栏。文档中的检测项开关只说明后台配置契约；场景不由文档顶部、URL参数或旧草稿默认指定。
