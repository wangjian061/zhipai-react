# 个人制作：规格与背景色联动

2026-10-22。用户已明确确认[结构样图](structure-approved.png)，本轮按该结构实现，待用户验收；本轮代码与文档纳入本次Git提交，未部署站点。

## 目标与边界

照片背景由所选规格对应配置决定，而不是前端按「一寸／驾驶证」等名称或尺寸写死规则。规格入口、选色抽屉和拍摄／选图后的现有制作页使用同一配置及校验。保留页面层次、照片展示区、快捷规格、更多规格抽屉及固定双按钮；不新增二次确认。不修改专项采集、六工具、付费价格或结果页购买行为。

配置现阶段仍为 `src/domain/photo-specifications.js` 的可替换本地数据，未接入后台、远程配置或真实识别。现有九项颜色组合只代表示例数据，不是永久业务规则或机构通用要求。

## 实现与流程串联

| 位置／状态 | 本轮行为 |
| --- | --- |
| 配置解析 | 按稳定 specId 解析对应 backgrounds，保留配置顺序，过滤重复、未知、停用及无有效名称／色值的项；同尺寸用途分别取配置 |
| 规格入口选色 | 仅显示当前规格的有效颜色；单色自动、多色失效清空；无有效配置或未选禁用「去拍照或选图」 |
| 相机／相册 → 制作前 | 入口与URL参数统一整理；保留已选规格；单色纠正为唯一选项，多色无效不悄悄选第一色 |
| 快捷／更多规格 | 一次提交规格及联动底色：原色允许则保留，单色自动，多色且原色失效则等待选择 |
| 制作前展示 | 颜色从左排列，32px色块、至少44px触控、12px间距；背景组下12px辅助文案及 status 播报；不新增卡片或弹窗 |
| 重拍／重选 | 保留当前仍有效的规格及底色；未选状态不会重新变成蓝色；原图取消保持，换图清旧结果与检测证明 |
| 草稿恢复 | 未付款参数按当前配置整理；失效结果返回制作前，保留原图和规格；未知规格显示不可用，要求另选，不伪造二寸；旧未付款收据原子停用，不绑定新输出 |
| 检测前／检测通过 | 再次校验可用颜色；多色待选或无配置时不能进入制作；单色可自动整理，配置变更不能绕过校验 |
| 制作与两版 | 请求启动后保存 specificationSnapshot 与 backgroundSnapshot；普通与精修继续使用同一规格、底色和原图 |
| 交易保护 | 已付款、待查款、已保存结果不因新目录改写参数或文件；新订单背景名称使用本次快照，原有查询、保存重试与金额不变 |

不支持的颜色不会作为备用选项出现；配置没有有效颜色时说明「当前规格的背景颜色暂不可用，请选择其他规格或稍后再试。」，保留原图及换规格能力。单色说明其限制，多色失效说明需重新选择。
