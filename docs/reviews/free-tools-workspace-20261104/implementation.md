## 实现范围

- 仅crop、background、format、resize四项使用inlineWorkspace。入口为空状态也直接显示各自设置，不渲染ToolStepper，不显示上一步。
- ToolWorkspacePlaceholder仅提供选图按钮；默认图没有photo／blob身份，不会进入检查和处理。原图与结果继续使用公共完整等比预览，外层保持透明。
- 四项底栏复用PhotoSelectionActions；empty为选取照片，selected为更换照片和当前保存／恢复操作。精修、换装与冲印流程保持。
- 所有有效来源直接进入当前页准备；保留适用设置，确认新照片清除旧输出和证明。同图、取消、失败、带图详情来源、原返回地址均有状态检查。
- 背景自动检查，未通过／取消／异常仍在当前页，禁止选色应用及保存；技术异常可重检，原因抽屉关闭为返回调整。通过后不留成功提示，准备实际结果。
- 四项完成页继续设备下载边界，不创建订单或写知拍相册；原有下载失败复用输出重试逻辑保留。重新开始回空工作页，焦点回默认图；返回原照片详情。
- 删除四份已取消的独立选图说明，归入各自完整工作页，运行时路由和目录同步，当前58份独立正文。产品、设计、设计JSON、交付和模块HTML说明同步。
