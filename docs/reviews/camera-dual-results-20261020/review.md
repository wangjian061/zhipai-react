## 已确认并实施

| 环节 | 当前行为 |
| --- | --- |
| 确认 → 检测 → 制作 | 保留原照片与九项预设、既有检测门禁及约5秒同页不可取消等待；演示控制明确标注原型 |
| 首次结果 | 同源同设置生成普通证件照198分（¥1.98）与精修证件照980分（¥9.80），同页等宽完整照片，名称与价格在照片外，无预选、一个解锁按钮 |
| 部分成功 | 两版均成功／仅普通版成功／仅精修版成功可演示；失败版保留原因及独立重试，成功版可购买。重试沿用保护等待与结果弹窗，只替换失败版 |
| 放大对比 | 既有深色查看语言，一个共享比例框、分割揭示及同步1～3倍缩放／拖动；客户端拖动距离按外壳缩放换算逻辑坐标后限界 |
| 交易身份 | 版本ID、名称、整数分金额与输出文件一起持久化；取消／待付款改选原子归档旧收据，失败保留原选择。待查款／已付款冻结身份，只查询原订单 |
| 保存 → 完成 | 付款或查询成功后只保存所购一版到知拍相册，保存成功进入完成；保存失败只重试保存，不再次付款。同次制作不再购买另一版 |
| 恢复与历史 | 刷新保留两版与选择；重试中断保留成功版。旧未付款常规规格结果可补配双版本且保留原输出；旧已付款／待查款单成片保留原金额和文件。未知、不支持的未付款规格回受支持确认，无自定义规格 |
| 其他业务 | 专项固定规格、拍摄前一次付款及任务回传保持；独立精修仍为¥2.00工具订单 |

## 能力与验收边界

两版是同一来源的Canvas输出。普通版不额外处理，精修版只做`brightness(1.045) contrast(1.025) saturate(1.02)`的轻量原型调整；没有接入或验证真实精修模型、照片质量、审核通过率或商业优势。付款仍为模拟。

遵守项目约定，未自动操作浏览器、截图或运行自动UI测试。实际首屏照片尺度、同位置滑杆与拖动手感、长原因滚动、读屏、系统权限、真机生命周期及照片质量仍待用户验收。源码／状态通过与构建通过分别记录，不替代实际画面或真机结论。
