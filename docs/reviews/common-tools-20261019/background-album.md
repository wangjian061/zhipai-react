## 用户路径

1. [更换背景](http://127.0.0.1:4180/?page=tool&tool=background&view=work)选取照片，在原型结果抽屉选择检查通过，直接进入换背景。
2. 选择底色，点击「保存到知拍相册」。保存中按钮显示「正在保存…」，避免重复提交。
3. 写入成功后显示「已保存到知拍相册」「原照片仍然保留」，照片和文件信息保留在完成页。「查看照片」进入刚保存的相册照片；「再处理一张」重新选图并重新检查。
4. 完成后无「上一步」，不能回到旧照片的编辑状态。保存失败保留当前照片、底色和处理结果，使用现有错误区与「重试」重新保存。

## 数据与恢复

- 新结果写入统一知拍相册，保留尺寸、规格、处理文件、原文件及来源照片ID；不覆盖原照片。
- 不自动下载，不创建付款订单；裁剪、格式转换和修改体积仍下载到设备。
- 重复点击不重复写入；写入后反馈异常时，重试更新同一个结果，保持一张结果照片。
- 保存途中退出页面，已提交的相册写入可以完成，但不跳回旧结果页、不覆盖新工具状态。
- 相册沿用当前原型的本地IndexedDB能力；未新增远程云端存储。
