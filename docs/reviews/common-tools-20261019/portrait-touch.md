## 本次改动与 oil-ui-pro 核对

精修、换装、更换背景复用同一个检测状态组件，两种恢复操作同时收敛到共享样式：

- 「查看原因」「重新检查」最小触控区由40px高调整为44×44px。
- 保留现有12px轻文字、状态文字颜色及透明背景，不加边框、阴影或新卡片。
- 文字在点击区内居中、不换行；使用正常布局扩大点击区，不用负边距覆盖其他内容。
- 卡片现有间距与状态说明保持原样；仅在44px操作区需要时随内容自然增高。

本轮只改共享CSS；检测组件、业务控制器及回调路径未修改。oil-ui-pro按现有项目规范完成源码检查，未自动操作浏览器、截图或开展独立视觉评审；实际观感与触摸由用户验收。
