日期：2026-10-19。用户已确认本轮方案：实际照片内轻蓝扫描、处理文字与对比标签外置，同类位置统一。当前已实现、待用户验收；C1、E1、E2未继续实施。

## oil-ui-pro方向与改动

本次为现有照片处理界面的一致性修复。照片是主角，动效只表达正在处理这张照片；不使用覆盖整个预览区域的深色遮罩或中央转圈，不生成虚假百分比，不延长业务处理时间。

| 范围 | 当前呈现 |
| --- | --- |
| 精修、换装、换背景的选图检查 | 共用选图照片内扫描；“正在检查照片”显示在照片下方；移除检查中的重复状态卡，失败和异常恢复保留 |
| 六项工具的实际照片处理 | 照片内轻蓝扫描，下方显示准备、精修、换装、更换背景、裁剪、格式或体积处理状态；付款和保存不启动照片扫描 |
| 精修效果 | 原对比滑杆保留；“精修前”“精修后”在照片下方左右两侧，12px辅助色、无底色，不再压住照片 |
| 拍摄确认与编辑预览 | 移除照片上的进度胶囊和转圈，复用扫描组件；确认页沿用照片下方状态说明，编辑预览的处理文字也位于照片下方 |
| 冲印固定比例裁剪 | 点击确认后仅对当前裁剪框内实际可见照片扫描，下方显示“正在裁剪照片”；排版资源读取与付款反馈保留原职责 |
| 专项采集制作中 | 有照片时在照片内扫描并在下方给出状态；没有照片时只保留简短说明，取消大块区域转圈占位 |

## 共用实现与边界

- `PhotoProcessingEffect`测量图片显示框、自然尺寸和object-fit，计算可见照片与父容器的交集，以百分比放置动效。横图、方图与窄人像的contain留白不参与扫描；冲印放大与位移后的框外部分也不参与。
- 图片加载、替换、容器尺寸及窗口变化时重新计算。图片未读入、读取失败、隐藏或不存在时不扫描，不沿用前一张照片的测量结果。
- 光带为轻蓝半透明渐变与细边线，2.2秒往返扫描；背景保持透明，动效不接管点击或拖动。处理完成、失败或离开时移除动效与测量监听。
- `PhotoProcessingStatus`复用12px辅助色文字；对比标签保持正常文档流。旧的图片内标签、工具区域遮罩、相机进度胶囊及无照片转圈样式已移除。
- 减少动态效果模式停用循环，保留静态光带和状态文字。未修改付款、保存、检查门禁、成功／失败分支及输出文件。

## 用户验收路径

1. [精修](http://127.0.0.1:4180/?page=tool&tool=repair&view=work)：选图查看检查动效，通过并完成原型付款后查看精修动效；完成后核对下方对比标签及原滑杆。
2. [裁剪](http://127.0.0.1:4180/?page=tool&tool=crop&view=work)、[换背景](http://127.0.0.1:4180/?page=tool&tool=background&view=work)：换用横图、方图及窄人像，核对扫描不进入留白。快速完成的本地操作不强行延长动效。
3. 拍摄后点击“使用照片”、冲印确认裁剪，核对扫描在照片内、文字在照片下；失败后动效停止并保留原恢复操作。
4. 核对窄屏、设备等比缩放和减少动态效果模式；真实图片比例、照片内容及裁剪结果保持不变。

本项实际效果经用户确认后，再继续原整改清单。
