日期：2026-10-19。范围：冲印及六项常用工具的各步骤、效果页和保存完成页。用户已确认统一标准；本项已由用户于2026-10-19确认通过。后续V2已实现待验收；C1、E1、E2未继续实施。

## 复核补充

上次V1审查只记录了精修与换装的40px触控区，漏查了同一返回动作的完整视觉一致性。复核确认三套独立样式并存：

| 原位置 | 源码现状 |
| --- | --- |
| 精修、换装操作与效果页 | 40px白色圆底、21px箭头；导航64px高、18px边距、标题18px；窄屏另改为14px边距 |
| 背景、裁剪、格式、体积及工具保存完成页 | 44px透明按钮、21px箭头；导航52px高、12px边距、标题17px |
| 冲印各页 | 44px按钮、12px圆角、22px箭头；独立导航与状态样式 |

原规范明确了44px触控区，但未完整收敛底色、图标、导航尺寸与交互状态。仅改40px为44px无法解决视觉不一致，本项已按用户新确认的完整标准处理。

## oil-ui-pro方案与实现

本次为现有照片工具导航的一致性整理，用户焦点仍是照片与当前处理任务。统一导航作为轻量次级控件，不增加描边、投影或业务提示。

- 44×44px白色圆底，20px深蓝左箭头，颜色复用 `--ui-heading`，图标复用现有 `i-chevron-left`。
- 导航52px高，左右12px留白，标题17px；左右各保留44px等宽槽位，右侧为空或有客服时标题都保持居中。长标题单行省略并保留完整标题属性。
- 按下缩放0.96，禁用透明度0.45、不触发按下缩放，焦点为2px知拍蓝外圈；沿用160ms动效节奏，减少动态效果时取消过渡。
- 所有入口复用 `ToolNavigation` 和同一份样式。原有工具专用返回样式、精修／换装64px导航和窄屏例外、冲印独立返回样式均移除。
- 顶部调用原有 `back()`，底部仍使用 `previousStep()`；选图／处理／排版步骤退出与回退职责不变，地址和订单子页面保留原来源路径。
- 本轮没有增加订单或分享入口，冲印原有订单结果页客服操作保留。

规范已同步至 [DESIGN.md](../../../DESIGN.md) 和[产品需求](../../product/common-tools-1.4.6.md)。未改工具或冲印业务控制器；相册保存整改保持不变。
