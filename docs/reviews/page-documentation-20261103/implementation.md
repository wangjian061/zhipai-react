## 3. 内容及业务边界

- 首页按批准样例完整比较八项工具来源、检查、收费和保存去向，独立精修¥2.00与个人制作精修版¥9.80分开。
- 工具分别说明选图、设置和结果；不同检测、参数、付费与下载规则按各工具契约，不因共享组件变为相同业务。
- 个人相机四页与专项两页独立，专项参数锁定项目、制作成功回传原任务，不进入个人版本购买。相机版本页补齐放大层、双版滑杆、缩放拖动、单版／已购版及预览失败恢复。
- 通知正文就近保留正常业务仍按最新记录生成快照、项目直进项目／系统提示的差异；历史、未读、公告演示不等于正式通知完成。服务四项固定帮助与已确认九项、共享邮件及后台维护分别记录。
- 采集详情保留240px完整照片、连续左右资料及当前状态动作；主卡无复制／补充／折叠，客服抽屉保留定位能力。扫码两类去向、15 MB、内存交接、旧帮助口径差异明确。
- 登录记住号码仍需验证、协议每次新流程未勾选，第三方授权后绑定、密码找回及注销边界各页独立。支付、短信、认证、审核、AI、物流与本地能力分开。
- 本页演示只在相应上下文出现，无场景页无空框。强更与三个结果在全局菜单，顶部唯一恢复不是正式App跳过升级；忙碌保护、原页面挂载和内存隔离保持。
