# 相册列表抽屉与统一删除：本地实施记录

日期：2026-11-06。范围基于用户确认的两张结构样图，以及最后补充「列表正确，但是照片详情应该和之前的保持一致」。当前交付用户验收，未提交、推送或部署。

本日后续用户确认将证件类型改为原地展开、去掉替换／补充并修复删除；以下证件相关内容保留为当时记录，当前实现与规范以[后续证件修订](document-inline-delete-20261106.md)为准。

## 最终实现

- 家人列表仍为底页；点成员打开同名公共抽屉，正文沿用三列照片与日期，固定底部添加照片。单张详情关闭回成员照片列表，恢复浏览位置；再关闭回家人列表。
- 单张照片复用`PhotoActionSheet`原有左图右资料、精选服务、固定下载的布局，未添加新的详情样式。家人原图经实际解码后开放放大、服务与下载，失败可重读。
- 个人、个人中心和家人单张详情在精选服务下方直接删除，不恢复「更多操作」；证件保留按面替换、补充、单面删除及整份删除的布局。
- 统一确认对话框、忙碌态、取消与失败重试。损坏文件不影响删除记录；删除家人照片只作用于该成员副本，删空保留成员。个人照片删除同步更新普通相册和个人中心。
- 产品说明、设计规范、机器可读设计记录、三端交付说明与左侧页面文档同步。成员照片列表、单张详情和删除确认对应各自文档段落。
