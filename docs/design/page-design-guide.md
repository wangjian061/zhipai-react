# 知拍（Zhipai）新页面设计指导手册

> 依据文档：[DESIGN.md](../../DESIGN.md) · [全项目消息反馈规范](message-feedback-guidelines.md) · [PRODUCT.md](../../PRODUCT.md)
> 适用对象：产品经理、设计师、AI 辅助设计与三端（iOS / Android / 鸿蒙）研发
> 目标：当后续出现任何新增页面或业务改版时，**先定页型、再套骨架、严守禁区**，确保全产品视觉清爽一致、交互连贯不跑偏。
> **核心审美基准（必要参考）**：**精致、小巧、充足留白、整洁、统一、布局整齐**。杜绝“大而且笨拙”的肥大控件、强拉撑满整行的胖胶囊与杂乱边框；辅助标签追求小巧克制（可见高 `26–28px`、`6px` 轻圆角，外层隐形保 `44px` 触区），同卡元素严守共同基线与左右对齐线。

## 一、新增页面决策速查表（先选页型，再做设计）

拿到一个新需求时，先判断它属于下表哪一种页面类型，直接复用对应的页面骨架：

| 页型 | 典型场景 | 顶部导航与返回 | 页面画布 | 主体容器 | 底部区域 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1. 一级聚合页** | 首页、相册、个人中心、新一级 Tab | 品牌吸顶头（安全区+92px，无返回） | `#F1F5FD` | `20px` 圆角白卡分组 | 悬浮液态底栏 |
| **2. 工具/定制工作页** | 新 AI 照片工具、冲印、明信片/邮票 | 白底固定 `52px` + 无底色纯箭头返回（按压 `#F1F5F9`） | `#F3F5FC` | 无图 4∶3 3D 头图 / 有图 5∶7 直角预览 + `16px` 参数白卡 | 固定操作底栏（`48px` 主按钮） |
| **3. 目录/列表/文件夹二级页** | 照片规格、家人相册/证件二级页、通知、帮助目录 | 常规白底+无底色返回；照片规格/专项主题头用透明+白圆返回 | `#F3F5FC` | `16px` 分组列表白卡（`1px` 细线）或独立对象白卡 | 无 / 固定底栏（如「添加照片/添加证件」） |
| **4. 独立搜索页** | 项目搜索、历史记录搜索 | 白底固定搜索头（无底色返回+44px输入+搜索） | `#F3F5FC` | `16px` 无阴影白卡条目 | 无 |
| **5. 表单/登录/设置页** | 收货地址、实名认证、反馈、登录/安全 | 白底固定 `52px` + 无底色纯箭头返回（按压 `#F1F5F9`） | `#F3F5FC` | `16px` 表单白卡（登录单屏无外卡） | 固定主按钮或表单内主按钮 |
| **6. 交易/订单/确认单** | 确认订单、订单列表、订单详情 | 白底固定 `52px` + 无底色纯箭头返回（按压 `#F1F5F9`） | `#F3F5FC` | `16px` 无阴影交易票据卡（虚线+6px缺口） | 付款底栏 / 确认收货底栏 / 无 |
| **7. 状态跟踪/任务详情** | 专项采集详情、审核/履约进度 | 带状态背景用透明+白圆；常规用白底+无底色返回 | 状态色或 `#F3F5FC` | 不透明 `#FFFFFF` 主卡 + 连续键值列表 | 固定当前状态主操作 |
| **8. 结果决策/完成页** | 双版本解锁、处理完成、下单成功 | 白底固定 `52px` + 无底色纯箭头返回（按压 `#F1F5F9`） | `#F3F5FC` | 预览/版本白卡或状态白熊+成片 | 固定结算或交付底栏 |
| **9. 沉浸/拍摄/深色层** | 相机、扫码、大图查看、成片对比、海报 | 透明悬浮白圆返回 或 深色 `44px` 半透明关闭 | `#17191D` / 实景 / 弥散 | 全屏取景框 / 居中完整照片 / 海报 | 相机快门 / 手势提示 / 分享操作 |
| **10. 轻交互覆盖层** | 选图、选色、照片详情、报错、二次确认 | 不开新页面：走 `SharedSheet` / `ConfirmationDialog` / `Toast` | `#121C2D` 48% 遮罩 | 顶部 `24px` 上滑抽屉 或 `16px` 居中确认框 | 抽屉固定底栏 / 弹窗双按钮 |

## 二、十大页面类型详细设计指导

### 类型 1｜一级主 Tab / 聚合门户页
> 适用：带底部主导航的一级入口页（如首页、相册、个人中心，或未来新增的一级 Tab）。

- **头部结构**：采用品牌吸顶头部（系统安全区 + `92px`），浅蓝弥散底色，右侧裁切小白熊贴合首张白卡上沿；向下滚动正文经过头部时切为磨砂半透明 + 轻阴影，系统减少透明度时回退 `#EDF3FF` 实底。
- **正文布局**：画布 `#F1F5FD`，左右 `16px` 留白，大区块间距 `20px`；每个大业务模块使用独立 `20px` 圆角白卡（`16px` 内边距、`--ui-card-shadow`），区块标题 `15px / 600` `#203858`。
- **底部留白**：正文末尾必须预留 `56px（导航高）+ 底部安全偏移 + 40px` 净距，防止末行内容压入悬浮底栏。
- **禁区**：一级页不放返回按钮；不在一个白卡内再套带阴影的二级白卡；不在首页直接承载复杂的认证、选图或支付流程。

### 类型 2｜照片工具 / 实物照片商品工作页
> 适用：两类高频工作流——① 照片处理工具（精修、换装、改尺寸、换背景、改格式、改大小）；② 实物照片商品（照片冲印、明信片、纪念邮折）。

- **路径原则**：**直接进入工作页，不拆独立“选图前置页”，不显示顶部步骤条**。
- **顶部与画布**：白底固定导航（`#FFFFFF`、`16px / 600` 居中标题、无底色纯箭头返回并在按压时显现 `#F1F5F9` 轻灰圆底）+ `#F3F5FC` 画布。
- **照片处理工具（以“用户照片处理前后”为核心）**：
  - 无图态顶部展示 `1200×896px`（4∶3）`16px` 圆角 3D 能力宣传头图，选图后切换为 `5∶7` 浅灰底 `#E9EDF3` 直角照片预览（最大宽 `250px`）；底栏无图「选取照片」，有图 `2∶3`「更换照片 + 主操作」。
  - 照片精修保持工作区极简（不前置放背景色卡，也不暴露后台“标准化”术语），背景色延后至确认付款抽屉内选择。
- **实物照片商品（冲印 / 明信片 / 纪念邮折，以“实体成品”为核心）**：
  - **页面主角必须是实体商品效果**（整版冲印相纸 / 实物明信片 / 纪念邮折），**绝不在选图后把单张用户原图放大霸占页面顶部**。
  - 页内统一三段结构：`顶部商品展示舞台 → 版式/模板选择 → 商品信息白卡`。冲印费用放在确认订单页，明信片与邮折商品卡保留价格。
  - 底栏默认常亮主按钮 **`上传照片 · 预览效果`** → 选图后无缝拉起 `SharedSheet`「定制预览 / 冲印预览」（在单层抽屉内完成成品预览、版式/模板切换、手势+紧凑滑杆手动裁剪/微调）→ 底栏 **`换一张 | 满意，去确认订单`**（已选图关闭抽屉回到商品页时底栏展示 **`继续预览 | 去确认订单`**）。
- **处理与校验**：需要人像检测的工具在选图后自动检测，通过不弹多余“通过提示”，不通过留在同页并提供「查看原因 / 重新检查」；处理中仅在照片内容区播放轻蓝扫描光带，不盖全屏 Loading 遮罩。
- **禁区**：严禁在照片下方或顶部增设第二个「更换照片」入口；严禁对用户未付费真图做假换色欺骗预览。

### 类型 3｜目录 / 分组列表 / 文件夹二级页
> 适用：照片规格、家人相册成员页、证件照片持有人页、项目分类、通知列表、帮助问题列表、未来新增的内容目录页。

- **头部选择**：
  - 常规目录与文件夹二级页（家人/证件二级页、通知中心、帮助列表）：白底固定 `52px` 导航 + 无底色纯箭头返回（按压 `#F1F5F9`）+ `#F3F5FC` 画布；人员文件夹 Push 进入新页面（隐藏底部主导航，原生支持边缘右滑返回），不塞进底部抽屉。
  - 品牌/主题头图页（照片规格 3D 样片头图、三类采集专题、采集记录）：保留透明导航 + `#FFFFFF` 白圆返回，让头图或浅蓝弥散背景自然延伸至系统状态栏。
- **分组列表白卡（优先于拥挤多列图标宫格）**：当条目包含「名称 + 用途/说明 + 数值/尺寸」三层信息（如照片规格）时，优先采用分组 `16px` 圆角白卡（组标题 `13px / 500` `#53637B` 置卡外上方），单行 `min-height: 56px`、`1px #EDF1F7` 细线分隔，左放主副文案、右放等宽数字与轻右箭头，不靠重复装饰图标凑数。
- **连贯宫格（仅限一级聚合页简洁功能入口）**：如首页常用工具，采用外层 `20px` 圆角白卡 + 内部 `12px` 外圆角 + `1px #F1F4F8` 细线无缝划分，主名称 `13px / 500`。
- **必配状态**：必须同时设计「加载占位」「空态」「筛选无结果」「读取失败 + 重新加载」。

### 类型 4｜独立搜索页
> 适用：全部/分类项目搜索，以及未来可能新增的相册/帮助/商品搜索。

- **头部结构**：白底固定搜索头（承托状态栏），内部横向排列 `44px` 无底色纯箭头返回（按压 `#F1F5F9`）+ `44px` 浅灰蓝输入框（`#F3F6FB`、`12px` 圆角）+ 搜索操作（可用宽度 `<212px` 时自动收起右侧文字按钮，优先保输入框）。
- **正文状态**：画布 `#F3F5FC`，正文独立滚动；未输入关键词时展示干净空态或历史引导，不堆砌全量列表；命中结果采用无阴影 `16px` 白卡，无结果给出清晰空态提示。
- **返回连续性**：从搜索结果进详情再返回时，必须恢复关键词、滚动位置与源条目焦点，且**不自动重新弹起软键盘**。

---

### 类型 5｜表单填写 / 登录认证 / 信息提交页
> 适用：账号登录与密码重置、收货地址编辑、意见反馈、新增信息提交页。

- **顶部与画布**：白底固定导航 + `#F3F5FC` 画布（登录主流程采用无外卡单屏极简排版；多字段表单采用 `16px` 圆角白卡分组，组间留白 `16–24px`）。
- **输入控件标准**：
  - 常规与抽屉表单：`min-height: 44px`、`12px` 圆角、`#F3F6FB` 底色、原生 `15px / 400`（Web 端保留 `16px` 防 iOS 聚焦放大）。
  - 账号全屏主输入：`height: 54px`、`12px` 圆角、启用等宽数字（`tabular-nums`）。
  - 字段标题左对齐（`13px / 500`），输入框与错误说明保持同一左边线。
  - **禁用原生 HTML `<select>` 下拉框**：正式业务界面禁止使用桌面 Web 下拉选择框；2–4 个短选项（如 `KB | MB`、「男装／女装／童装」与邮折「中央大图／四角小图」）使用高对比分段控制器（`#FFFFFF` 白底配 `1px #DCE3EE` 边框轨道 + `#203858` 深蓝实底白字选中块，同心圆角 `10px / 7px`）或单选预设胶囊，≥5 个选项统一弹 `SharedSheet` 单选。
- **协议与提交**：协议勾选框（默认不勾选、`44px` 触控高度）永远放在主提交按钮之前；提交中按钮切为「正在提交…」并禁用防重复。
- **报错规则**：校验错误直接显示在对应字段下方（`12px` `#DC2626` + 清晰修正建议），**绝不用全局 Toast 代替字段报错，也绝不清空用户已填的其他有效字段**。

### 类型 6｜确认订单 / 支付 / 交易票据页
> 适用：冲印/纪念品/新付费业务的确认订单页、统一订单列表与详情页。

- **统一视觉**：白底固定导航 + `#F3F5FC` 画布 + `16px` 圆角**无阴影**交易票据白卡；表头与购买内容区之间以 `1px #D6DFEC` 虚线和两端 `6px` 半圆缺口形成票据语言。
- **金额排版**：全项目统一 `#E11D48` 全局金额红 + 等宽数字，保留两位小数；列表/卡片金额 `16px / 700`，确认底栏/详情大金额 `20px / 700`，`¥` 符号 `12px / 600`。
- **支付与中断恢复**：
  - 渠道分流遵循平台规则（iOS 中国区 App 内数字权益走 IAP，实物与外部服务提供微信/支付宝）。
  - 发起支付前记录原单 ID 与业务位置；切回或重开自动查款；**结果未知时同位展示浅琥珀 `PaymentRecovery` 提示条与「查询支付结果」**；确认未付显示「本次尚未支付」+「继续支付」沿用原单；扣款后制作/保存失败仅重试处理或保存，严禁重复建单或收费。
- **禁区**：订单卡片禁止点击缩放或展开转场；订单中心只负责交易查询与实物确认收货，不混入看大图、下载或二次处理入口。

---

### 类型 7｜任务详情 / 状态跟踪页
> 适用：专项采集详情、审核进度页、未来新增的异步制作/申诉跟踪页。

- **背景与头部**：
  - 若业务强依赖状态感知（如待拍/制作中 `#1677FF`、待提交/审核中 `#D97706`、已完成 `#059669`、失败 `#DC2626`），整页采用对应状态色浅/实底背景，头部用透明导航 + `#FFFFFF` 白圆返回，状态标题统一近黑 `#1D1D1F`、说明 `#3F4248`。
  - 常规无强状态背景的详情页，沿用白底固定导航 + `#F3F5FC` 画布。
- **主卡排版**：不透明白色 `16px` 主卡（不做磨砂模糊），上方展示等比直角照片（如有），浅虚线下方排布连续的键值信息列表（左标签 `12px` `#73849A`，右数值 `13px` `#203858`，长值自然换行不截断）；不套二级子卡或冗余折叠。
- **禁区**：不把“审核状态”和“付款状态”混写在同一句或同一胶囊里；缺失数据如实省略或写「未提供 / 未记录」，绝不编造占位值。

---

### 类型 8｜结果展示 / 对比决策 / 处理完成页
> 适用：证件照双版本解锁页、六工具统一完成页、实物下单成功页。

- **双版本/多方案决策页**：
  - 优先预选一个合理可用版本，让底部主按钮立即可用（仅全部不可用时禁用）。
  - 整张版本卡片均可直接点击切换；用**清晰的单一层级反馈**（浅蓝底 `#F3F7FF` + `1.5–2px` 知拍蓝描边 + 单一勾选标记）表达选中，**绝不叠加外卡套内卡 + 边框 + 底线 + 多个重复图标**。
  - 每个方案用一句话讲清差异与价格（`16px / 700` `#E11D48`），底栏左侧 `20px / 700` 价格 + 右侧 `48px` 主按钮。
- **终态完成页**：
  - 取消顶部步骤条与底部「上一步」；顶部用 `56px` 主题白熊 + `16px / 600` 交付状态 + `13px` 简短说明，下方展示成片与核心参数。
  - **已进入完成页时，不再叠加“保存成功/付款成功” Toast 或弹窗**。
  - 未解锁结果点返回时，弹出居中确认框说明丢弃后果（保留原图与设置）。

---

### 类型 9｜全屏沉浸 / 拍摄 / 扫码 / 深色看图层
> 适用：拍照取景、扫码识别、独立大图查看、成片放大对比、分享海报页。

- **视觉规则**：全屏实景、`#17191D` 深底或蓝紫弥散背景延伸至屏幕边缘；顶部避让安全区后放置悬浮 `44px` 返回/关闭按钮（深色层为半透明白底 + 白色图标，状态栏与 Home 条同步切白色）。
- **移动端优先手势**：
  - 大图与对比层必须优先支持**图上直接左右拖动分割手柄（44px 触区）、双指捏合缩放（1–3×）、双击放大/还原、放大后单指平移**；**禁止在手机端堆砌笨重的桌面端双滑杆或常驻加减工具条**（仅在放大后显示轻量「点击还原」按钮）。
  - 缩放时按触点/中心保持当前视口位置，不粗暴重置归中。
- **禁区**：严禁在全屏/深色页面顶部硬加白色实底导航栏；底页必须锁定滚动，关闭层后精准恢复来源位置与触发焦点。

### 类型 10｜容器决策树：什么时候“不要新建页面”？

遇到新交互节点，**默认先问能不能用更轻的层级解决**，避免页面链路越来越长：

1. **只告诉用户结果、不需要任何后续操作**（如「已复制」「已发起下载」）
   → 用 **Toast 轻提示**（`#26364A` 深蓝灰、`12px` 圆角、位于当前导航/操作栏上方 `16px`，单行约 2 秒消失）。
2. **需要用户对不可逆或关键后果做二选一**（如删除照片、丢弃未解锁成片、超 1MB 压缩上传、确认收货）
   → 用 **居中确认框 `ConfirmationDialog`**（最大宽 `300–320px`、`16px` 白卡、`16px / 600` 标题、底部两个明确动词按钮，不用“是/否”）。
3. **不打断主流程上下文的选型、查看、报错或补充操作**（如选图、选规格/底色、照片详情、调整构图、客服联系、检测/制作失败原因、获取采集码帮助）
   → 用 **公共上滑抽屉 `SharedSheet`**（顶部 `24px` 圆角、**统一左对齐 `16px / 600` 标题 + 右上 `44×44px` 关闭按钮**、正文独立滚动、底部固定主按钮）。
4. **只有满足以下任一条件时，才新建独立二级页面（Push 进栈，支持边缘右滑返回）**：
   - 属于文件夹/容器型浏览空间（如「{称呼}的照片」「{称呼}的证件」），内部需滚动浏览并承载批量管理/添加/详情等子操作；
   - 需要承载多组表单、结构化目录或独立搜索（如照片规格、搜索页）；
   - 流程本身是完整独立任务或终态结果（如确认订单、完成页、订单详情、账号安全）；
   - 需要独立 URL 路由、跨业务回跳或系统分享承载。

## 三、新页面出稿前 10 项必检清单（Design Gate）

任何新页面在评审或交付编码前，必须逐项勾选以下 10 条：

- [ ] **1. 导航与背景配对正确**：常规二级页（含家人/证件二级页）是「白底固定导航 + 无底色纯箭头返回（按压 `#F1F5F9`）+ `#F3F5FC` 画布」，照片规格/专项头图/状态色/相机/深色页保留圆底返回且未误切白底顶栏。
- [ ] **2. 色系纯粹无串色**：全页使用知拍蓝灰体系（`#0032FF` / `#203858` / `#53637B` / `#73849A`），金额统一 `#E11D48`，错误/危险统一 `#DC2626`，未混入其他灰色或营销亮色。
- [ ] **3. 字号清爽、字重合规**：常规标题 ≤ `18px`、主金额 ≤ `20px`、常规可读文案 ≥ `12px`，字重仅用 `400 / 500 / 600 / 700`（无 `650`），数字类信息启用等宽数字。
- [ ] **4. 精致小巧、留白整齐、去线降噪**：整体精致不笨重，辅助标签小巧克制（`26–28px` 视觉高 + `44px` 透明触区）且不硬撑满行；卡片内边距与区块留白充足、左右严守对齐线；没有“白卡套带框白卡”，选中态只用单一清晰信号，不叠多层边框与凑数图标。
- [ ] **5. 照片比例与圆角合规**：工作区/确认原图/大图查看严格直角 `0px` 且 `contain` 完整展示，不拉伸、不裁脸、不被无关角标或大遮罩挡住。
- [ ] **6. 触控、选择控件与 5 类标准按钮达标**：所有可点击热区 ≥ `44×44px`；**正式业务 UI 未使用原生 `<select>` 下拉框**（改用分段控制器/预设胶囊/`SharedSheet`）；主/次/强危险按钮 `48px`、`14px` 圆角；轻危险按钮仅用于无主按钮紧邻的独立危险动作；每屏突出唯一主 CTA。
- [ ] **7. 抽屉与弹窗规范统一**：抽屉统一复用 `SharedSheet`（顶部 `24px` 圆角、左对齐 `16px / 600` 标题 + 右上 `44px` 关闭），不另写野抽屉；确认框按钮写明具体动作；Toast 靠下居中避让操作栏与键盘且不在登录/完成页叠加冗余成功提示。
- [ ] **8. 异常与边缘态完整**：已定义空态、加载态、禁用态、弱网/失败重试、长文案换行及超限处理，不编造假数据或假进度。
- [ ] **9. 流程闭环串联**：明确了“从哪来（上一步）→ 本页做什么 → 去哪（下一步）→ 取消/返回/重开后如何恢复原状态与焦点”。
- [ ] **10. 三端与无障碍适配**：未把 Web 预览 `402×874 / 62px / 29px` 当硬编码值；兼容窄屏（360px）、系统大字体、键盘避让、`prefers-reduced-motion` 及键盘焦点环。
