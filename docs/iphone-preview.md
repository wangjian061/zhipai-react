# iPhone 16 Pro 预览外壳

2026-10-14，按用户确认为所有页面增加统一 iPhone 轮廓、状态栏、灵动岛与底部操作横杠；同日按用户反馈改为透明固定状态栏及沉浸式页面。仅修改 React 原型，访问端口仍为 4180。

## 尺寸基准

来源：[Apple iPhone 16 Pro 技术规格](https://support.apple.com/zh-cn/121031)。官方屏幕像素为 1206×2622，机身宽高为 71.5×149.6 mm。

- 预览采用 3× 屏幕换算的 402×874 逻辑尺寸，机身比例绘制为约 430×900。
- 屏幕与外壳左右间距各 14，顶部与底部各 13。
- 状态区域高 62，底部操作区高 34；应用背景使用完整 402×874 屏幕，控制内容逐页避开系统区域，不再缩成中间 402×778 的独立块。
- 外壳绘制圆角、深色屏幕边框、金属轮廓与侧边按键。状态栏固定显示 9:41、信号、Wi-Fi 和电池；这些是预览装饰，不读取设备通信状态。
- 状态栏与底部操作区均为透明固定浮层。相机拍摄阶段采用白色标识，其余采用深色标识。
- 浮动菜单底边距屏幕底部 29；横杠底边距屏幕底部 8，高 5，因此菜单与横杠间隙为用户选定的 16。整机缩放时该间隙一起等比缩放。

## 结构与交互

`DevicePreview` 只负责按窗口大小等比缩放整机，不改变屏幕逻辑尺寸；大窗口最大为 1 倍，小窗口留边后适配整机宽高。窗口缩放监听与尺寸观察在卸载时清理。

`NativePhoneChrome` 的状态栏和底部横杠采用 fixed 定位，屏幕自身建立固定定位的包含块，系统标识相对于手机屏幕固定，不跟随页面滚动。两者层级为 1000；页面及抽屉处于独立的较低层级，无法覆盖系统标识。

页面、悬浮导航、抽屉挂载点与照片选择器统一放入铺满屏幕的 `app-viewport`。常规页面为顶部内容留 62；带宣传图、IP 或背景的入口在背景内部安放内容，背景延伸到屏幕顶端。首页横幅保留原图片比例；服务说明卡片和工具内部布局保留。

首页轮播图片从屏幕顶边开始，不为状态栏增加顶部空白或下移图片。状态栏叠在原图片上；轮播操作文字位于右下方，避开系统标识及容器卡片的叠压区域。

首页、相册与专项采集菜单共用 29 的底部位置；固定操作栏及抽屉末端也保留横杠间距。相册卡片继续与菜单分开，页面及照片的滚动责任沿用原设计。

专项采集流程操作栏的底部安全间距只应用于专区内的操作栏，不应用于首页同名入口卡片；首页入口恢复原有 62 高度与内边距，避免标题和说明被挤入宣传图片区域。

水滴菜单把缩放后的测量值转换回逻辑坐标，整机尺寸变化时重新定位；首页菜单模糊层的触发距离也按逻辑坐标计算。相机及工具的照片拖拽原本以可视区域比例计算，不改动照片裁剪规则与输出尺寸。

## 结果与验收边界

- 5 项设备比例、窗口适配、菜单缩放位置、亚克力层触发距离及结构边界检查通过；检查已更新为透明固定浮层、全屏内容与 16 间距。
- 初始绑定与迁移保护检查通过；只调整已明确授权的外层容器数量，保留其余页面结构及文案校验。
- 既有水滴菜单动画的状态与几何回归通过。
- React 构建通过，本地首页、外壳组件、状态栏组件与新样式均返回 HTTP 200。
- 未自动操作浏览器、截图或运行自动 UI 测试；实际视觉、触摸与键盘状态待用户预览。没有进行独立视觉评审。
