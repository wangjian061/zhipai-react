# 知拍 1.4.6 常用工具产品需求与验收

更新：2026-10-21。适用：知拍 React 原型的冲印、照片精修、照片换装、更换背景、照片裁剪、格式转换、修改体积。最新确认覆盖旧版冲突要求。

本模块让用户选取一张照片，完成当前处理并取得结果。每次修改必须串联上一页、当前页、下一页；用户验收当前结果后再推进后续修改。同一功能复用同一交互和视觉组件，每个步骤只承担当前任务。

配套材料：[逐页交互式结构示意](common-tools-1.4.6.html)、[逻辑校验与整改清单](../reviews/common-tools-20261019/review.md)、[通用视觉规范](../../DESIGN.md)。结构示意用于对照页面职责，不作为实际页面截图或视觉验收结果。

## 一 业务规则与实现边界

| 工具 | 照片来源 | 内容或比例检查 | 后续操作 | 收费与结果 |
| --- | --- | --- | --- | --- |
| 照片精修 | 知拍相册、手机相册 | 单人正面证件照 | 选择背景色、付款后精修、前后对比 | ¥2.00；自动保存到知拍相册 |
| 照片换装 | 知拍相册、手机相册 | 单人正面证件照 | 选服装、付款后换装 | ¥2.00；自动保存到知拍相册 |
| 更换背景 | 知拍相册、手机相册 | 单人正面证件照 | 准备照片、选择背景 | 免费；保存到设备，保留原照片 |
| 照片裁剪 | 知拍相册、手机相册 | 不检测照片内容 | 预设尺寸、手动构图 | 免费；下载到设备 |
| 格式转换 | 知拍相册、手机相册 | 不检测照片内容 | JPG、PNG 转换 | 免费；下载到设备 |
| 修改体积 | 知拍相册、手机相册 | 不检测照片内容 | 设置 KB、MB 体积上限 | 免费；下载 JPG，像素尺寸不变 |
| 冲印 | 知拍相册、手机相册 | 仅检查 5∶7 比例，不检测人物 | 不符合比例先裁剪，再选排版、地址、付款 | 每单一版¥19.80＋运费¥10.00，合计¥29.80 |

- **已确认且已实现**：取消工具介绍首页；共享选图抽屉；换图集中在选图阶段；通过即前进、未通过停留；结果继续操作从选图开始；右上不放订单入口；圆形序号步骤条。
- **原型模拟**：人像检查通过人工选择“通过／不通过／异常”；精修为本地滤镜、换装为服装图叠加；付款、物流及配送报价使用本地演示逻辑。不得将这些表述为已接入真实检测、AI、支付或物流服务。
- **真实本地能力**：图片读取、Canvas 裁剪、JPG／PNG 转换、压缩、简单背景换色、浏览器下载、IndexedDB 保存。
- **独立业务边界**：个人证件照制作、专项采集不纳入本次工具修改；个人制作的双版本解锁与独立精修服务分别计费。证照规格使用独立目录，不计入本次六工具整改。
- **技术输入边界**：手机相册支持30 MB以内的 JPG、PNG、WebP；无法读取的文件保留当前流程并提示“照片无法读取，请选择30 MB以内的 JPG、PNG 或 WebP。”。这是文件校验，不是人像内容检测。

## 二 统一流程与导航

| 工具 | 第一步 | 第二步 | 第三步 |
| --- | --- | --- | --- |
| 精修 | 选照片、证件照检查 | 照片精修：选背景色、付款和处理 | 处理完成（自动相册交付） |
| 换装 | 选照片、证件照检查 | 选服装、付款和处理 | 处理完成（自动相册交付） |
| 换背景 | 选照片、证件照检查 | 换背景 | 处理完成（设备交付） |
| 裁剪 | 选照片 | 裁剪 | 处理完成（设备交付） |
| 转换 | 选照片 | 选格式 | 处理完成（设备交付） |
| 体积 | 选照片 | 调体积 | 处理完成（设备交付） |
| 冲印 | 选照片，必要时固定比例裁剪 | 选排版 | 确认订单、付款结果 |

顶部返回退出当前工具并回到来源，不代替步骤回退；抽屉打开时优先关闭抽屉。底部“上一步”只回到前一流程阶段，保留当前照片和有效设置；第一步不再提供“上一步”。完成状态结束本次处理，不允许返回旧编辑步骤；继续使用必须重新选图。

需要证件照检查的工具，通过后直接进入下一操作，不弹通过提示；未通过停留第一步，不得进入制作、付款或导出。冲印只判定比例：一寸25×35 mm与二寸35×49 mm均为5∶7，小二寸35×45 mm不等同；常见像素取整误差允许通过。

## 三 按页面说明

每节按顶部、主体、操作区和页面职责排列。每页的结构和状态可在配套示意中切换；未明确修改的页面沿用现有布局。

### P01 工具选照片页

[页面示意](common-tools-1.4.6.html#p01)

1. 顶部：52px导航高、左右12px留白，左侧44px白色圆底返回、20px深蓝箭头，工具名称17px居中；右侧不放订单与分享。冲印和六项工具各步骤与完成页均使用同一导航组件。操作阶段下方为圆圈序号、连接线和文字组成的三步进度，不支持点击跳步；完成页不再展示步骤条。
2. 未选图：小白熊、“选取一张照片”、“知拍相册 / 手机相册”；直接放在页面背景，不包白卡。
3. 已选图：照片居中，下方12px间距为12px灰色规格文字，再下方是16px图标＋13px蓝字“更换照片”，无底色，点击高度至少44px。照片完整适应5∶7预览区，余区浅灰，不拉伸、不自动裁切原图。
4. 底部：未选图为“选取照片”；从后续步骤返回后为“下一步”。后续步骤不另放换图入口。
5. 交互：打开选图抽屉；取消保留照片和设置；重新确认同一照片保留设置；确认新照片清除旧输出并重新执行该工具的检查。带照片从其他入口进入时可跳过重复选图，但不能绕过必要检查。

### P02 选择照片抽屉

[页面示意](common-tools-1.4.6.html#p02)

1. 固定头部：“选择照片”、右上关闭；其下说明选择范围。
2. 固定来源区：“手机相册”、“制作一张”、“知拍相册”、照片数量。只支持单选；不出现“进入相册编辑”。
3. 独立滚动区：三列照片及选中标记。加载为“正在读取照片…”；空列表为“知拍相册暂无照片”；读取失败为“相册暂时无法读取，可重试或从手机相册选图。”，提供“重新读取”。
4. 固定底部：“使用这张照片”；未选中有效照片时禁用。只有照片列表滚动，标题、来源和确认区不跟随滚动。
5. 手机相册取消不换图；“制作一张”进入个人制作，完成后将新成片带回当前工具。

### P03 证件照检查阶段

[页面示意](common-tools-1.4.6.html#p03)

1. 保留第一步、当前照片及统一换图位置。检查时在实际照片内使用轻蓝扫描光带，避开四周留白；“正在检查照片”置于照片下方，操作暂时禁用。不叠加整区遮罩、转圈或重复的检查状态卡。
2. 原型使用“选择照片检查结果”抽屉，提供“符合要求 · 通过”、“不符合要求 · 不通过”、“模拟检查异常”，只用于演示。
3. 通过：关闭结果选择，自动进入下一步，不显示“检测通过”卡片或通过确认按钮。
4. “查看原因”“重新检查”共用至少44×44px轻文字操作，居中且不换行。未通过：“照片不符合证件照要求”、“查看原因”；底部“下一步”禁用，换图仍可用。检查异常：“照片检查未完成”、“重新检查”。关闭检查结果选择也不能当作通过。

### P04 未通过原因抽屉

[页面示意](common-tools-1.4.6.html#p04)

1. 固定标题“照片检查未通过”、关闭；正文标题“请重新选择人像证件照”。
2. 原因包括：不是人像证件照、未识别到清晰人脸、照片包含多人、背景较复杂。详细原因只通过“查看原因”进入抽屉，不在页面堆叠长文。
3. 底部“返回选照片”关闭原因抽屉，回到第一步；换图仍使用页面唯一的“更换照片”入口。

### P05 照片精修操作页

[页面示意](common-tools-1.4.6.html#p05)

1. 顶部和第二步均使用“照片精修”，去除可见的“AI精修／AI修复”旧称；主体为当前照片、必要文件信息，其下单独一组“背景颜色”。背景色为蓝色、白色、红色、浅灰，初始不预选，必须主动选择一种。沿用32px色块、12px名称与至少44px触控，选中蓝圈加勾，原生单选及键盘焦点，白色与浅灰保留边界。
2. 组标题旁未选时显示“请选择一种”，选后回显名称；未选择时“付款并开始精修”禁用，付款与处理入口同时校验。选色只设置本次成片目标，处理前仍完整展示原照片，不生成底色预览；不新增步骤或二次确认。底部左“上一步”回到选图；右主操作打开原付款抽屉。已有已付款订单且尚无结果时使用“开始精修”，不得重复收费。
3. 同一照片回退再继续、关闭付款或明确未付款均保留底色；确认另一张照片后清除底色、旧输出与订单草稿并重新检查。未付款原单改色再付款复用同一ID并更新快照；付款待确认或已付后锁定本单底色，处理与恢复使用原单快照，不读其他工具的默认蓝色。
4. 付款后进入处理；动效限制在实际照片内，处理文字置于照片下方。处理失败保留原图、已付原单和底色，重试原输入；保存失败只重试已有产物的保存。旧已付订单无底色字段时保留原处理契约及原输出，设置区显示“沿用原订单”，不补造底色或强迫重买。
5. 底色记录为`repairBackground: {id,name,value}`，购买摘要同时保存`purchaseSnapshot.backgroundName`。当前仍用本地滤镜加边缘连通底色替换模拟精修，只适用于简单背景；目标原生端需用同一参数接入真实处理接口，不能把本地效果视为已接入AI。

### P06 精修与换装付款抽屉

[页面示意](common-tools-1.4.6.html#p06)

1. 标题按场景为“开始照片精修”或“确认换装订单”，展示照片、服务、¥2.00及支付方式；精修服务名下回显本单所选背景色。
2. 支持原型付款成功、取消、失败；取消文案“已取消付款，照片与设置已保留”，失败文案“付款未完成，可重试”。
3. 确认后成功记录付款并开始对应处理；同一订单重试不重复创建交易。付款前不能生成付费结果。
4. 订单只记录交易与服务快照，照片结果保留在工具及相册，不把交易字段塞入图片编辑区。

### P07 精修处理完成页

[页面示意](common-tools-1.4.6.html#p07)

1. 自动保存成功后进入六工具共用的“处理完成”页，不再停留原效果工作页；完成页不展示步骤条。
2. 上方简短显示“已保存到知拍相册”“原照片仍然保留”，56px主题白熊仅辅助状态。主体保留前后滑杆；“精修前／精修后”在照片下方左右两侧，不遮挡照片。
3. 下方显示“照片精修 · 白色背景”等本次底色摘要及实际像素／格式／文件体积；无底色的历史订单仅显示照片精修。底部固定左侧次按钮“再处理一张”、右侧主按钮“查看照片”；查看直达本次成片详情，再处理回选图，底色重置未选。无上一步，历史照片与订单保留。
4. 自动保存失败仍留处理页，显示“保存未完成，已付款的照片已保留。重试保存不会再次收费。”；固定主按钮唯一提供“重试保存”，复用本次产物，不重新处理、不再次收费、不重复新增相册项。

### P08 换装选服装页

[页面示意](common-tools-1.4.6.html#p08)

1. 顶部“照片换装”，当前为“选服装”；主体保留当前照片。
2. 分类“男装／女装／童装”，各有“西装／衬衫／休闲装”；选中项明显但不遮挡照片。
3. 底部“上一步”回选图，“开始换装”在选择照片与服装后打开付款抽屉。付款成功才开始处理；动效只在实际照片内轻扫，“正在换装”显示在照片下方。
4. 新订单保留原照片像素尺寸；标准化为原型准备步骤，不表示真实AI处理。

### P09 换装处理完成页

[页面示意](common-tools-1.4.6.html#p09)

1. 保存成功进入与精修及免费工具共用的“处理完成”页；不展示步骤条。
2. 状态为“已保存到知拍相册”“原照片仍然保留”，主体为换装结果；照片下展示服装分类、服装名称及实际像素／格式／文件体积。
3. 固定底部为“再处理一张”与“查看照片”，行为同P07。保存失败只重试保存，保留已付款结果；原工具恢复已保存结果直接进入完成页，不重复生成或收费。

### P10 更换背景操作页

[页面示意](common-tools-1.4.6.html#p10)

1. 顶部“更换背景”，第二步“换背景”；检查通过后自动准备照片。
2. 主体照片与“背景颜色”，提供蓝色、白色、红色、浅灰；颜色单行横向滚动。
3. 此阶段不展示检查通过结果，也不展示“标准化已完成”。
4. 底部“上一步”回选图，“保存到设备”发起当前结果的浏览器下载；不写知拍相册、不创建订单、不覆盖原图。该规则于2026-10-21覆盖旧版背景写相册要求。
5. 发起下载后进入统一完成页，显示“已发起下载”“请在手机相册中查看”及所选底色、实际文件信息；固定底部“再处理一张”。保存调用失败保留照片、底色与产物，“重试保存”只重试导出，不重新制作；历史已保存的背景照片不删除。

### P11 照片裁剪操作页及手动裁剪抽屉

[页面示意](common-tools-1.4.6.html#p11)

1. 顶部“照片裁剪”、第二步“裁剪”；主体为照片与裁剪尺寸。
2. 尺寸包含一寸25×35 mm、二寸35×49 mm、小二寸35×45 mm；全原型不提供自定义尺寸或比例。
3. “手动裁剪”打开裁剪抽屉，支持拖动、缩放；“完成”应用裁剪。该独立工具的比例随所选尺寸改变，不受冲印固定5∶7规则限制。
4. 底部“上一步”回选图，“保存到设备”取得当前结果；失败保留调整并提供重试。

### P12 格式转换操作页

[页面示意](common-tools-1.4.6.html#p12)

1. 顶部“格式转换”、第二步“选格式”；主体照片、源格式、JPG／PNG选项。
2. 选择格式后生成预览，像素尺寸保持原值；有有效结果才允许保存。
3. 底部“上一步”、“保存到设备”；导出扩展名与文件真实类型一致。

### P13 修改体积操作页

[页面示意](common-tools-1.4.6.html#p13)

1. 顶部“修改体积”、第二步“调体积”；主体显示原文件信息和“目标体积”输入，单位KB／MB。
2. “目标文件体积”以“不超过”输入值、KB／MB单位和“应用体积”确认；范围为5 KB—20 MB的文件体积上限；压缩保持像素尺寸，输出JPG。不是扩大文件到指定大小。
3. 无法达到上限时说明“保持当前像素尺寸，最小约为 100 KB，请增大目标体积。”，数字读取当前结果，不虚构达标。
4. 底部“上一步”、“保存到设备”；改值后重新计算，不能保存旧参数下的结果。

### P14 六工具共用处理完成页

[页面示意](common-tools-1.4.6.html#p14)

1. 六项工具统一复用ToolResult。顶部“处理完成”、圆形返回；完成后不显示步骤条。正文独立滚动，底部操作固定，使用公共底部安全区。
2. 小幅主题白熊与交付状态在上方，照片为主体；使用5∶7浅灰预览区完整等比展示，最大236px宽，不拉伸、不裁切文件。精修保留滑杆及照片外标签；其余展示单张结果。
3. 照片下为14px任务摘要与12px真实文件信息。裁剪显示规格及毫米；背景显示底色；格式显示源格式→输出格式；体积同时显示目标上限与实际结果；换装显示分类和服装名称。
4. 背景、裁剪、格式、体积均手动保存到设备；完成显示“已发起下载”“请在手机相册中查看”，固定主按钮“再处理一张”。浏览器只能发起下载，不能确认已写入手机相册，原生端按目标能力还原。
5. 精修、换装保留自动相册交付及业务恢复，完成后显示相册状态；底部右侧主按钮“查看照片”直达本次结果，左侧次按钮“再处理一张”。本轮不增加付费工具的设备导出按钮。
6. 完成后不提供“上一步”，无法修改旧结果；再处理回全新选图状态，原图、历史相册与订单保留。同一完成流程不能再次保存。进入完成页聚焦状态标题，再处理后焦点回到选图入口。
