## 页面目标与流程

打开相机 → 拍照或相册选图 → 确认原照片、选择目标尺寸与底色 → 开始制作 → 查看成片 → 按需调整成片 → 原解锁与保存流程。

确认阶段只判断照片是否可用、确定输出规格。裁剪、拖动、缩放和构图调整留在制作结果阶段；不能要求刚拍照或选图的用户先手动构图。

## 确认页：从上到下

| 区域 | 展示与操作 |
| --- | --- |
| 导航 | 「确认照片」。拍照来源返回拍摄，相册来源返回原来源页；顶部返回不打开选图。订单中心原返回优先规则保留 |
| 原照片 | 完整显示，不拉伸、不强制填充，不增加外卡。选择目标底色不代表原照片已经完成换底 |
| 换图入口 | 照片下方轻文字。拍照来源「重新拍摄」，相册来源「重新选择」。取消保留照片与当前参数 |
| 核对说明 | 「请确认人像清晰、正面无遮挡」。不额外重复询问是否确认，也不代表已接入真实人像检测 |
| 照片尺寸标题 | 左侧「照片尺寸」，右侧显示当前规格。常用尺寸显示毫米值；大一寸显示「大一寸 · 33 × 48 mm」；自定义显示「自定义 · 600 × 800 px」 |
| 紧凑尺寸入口 | 一行「一寸／二寸／小二寸／更多尺寸」。标签只显示名称，视觉高度约32px，触控区44px，不再使用58px高的双行卡片 |
| 背景颜色 | 蓝、白、红、灰、透明，色块配名称及选中勾选，单行不足时横向滚动。默认蓝色 |
| 固定操作区 | 只保留「开始制作」，小屏只滚动正文，不遮挡主操作 |

默认尺寸仍为二寸。选择更多预设或自定义后，「更多尺寸」入口突出显示，并在标题右侧明确回显实际目标，不能让用户猜当前使用哪种尺寸。

## 更多尺寸：上滑抽屉

| 从上到下 | 职责 |
| --- | --- |
| 固定头部 | 标题「选择尺寸」和关闭按钮 |
| 可滚动正文 | 「预设尺寸」列表，每项显示名称、物理尺寸及输出像素，选中时显示勾选；下方为「自定义尺寸」 |
| 自定义区 | 选中后展开宽度（px）、高度（px）两个输入框；初始带入当前规格的像素值。输入文字16px，触控高度至少44px |
| 固定操作区 | 「使用此尺寸」。确认后提交选择并关闭，未确认关闭不更改当前目标 |

抽屉不展示照片、裁剪框、拖动提示、缩放滑杆或重置位置。标题、关闭和底部操作固定，仅规格与表单正文可滚动。

### 首版预设目录

| 名称 | 物理尺寸 | 输出像素 |
| --- | --- | --- |
| 一寸 | 25 × 35 mm | 295 × 413 px |
| 二寸 | 35 × 49 mm | 413 × 579 px |
| 小二寸 | 35 × 45 mm | 413 × 531 px |
| 大一寸 | 33 × 48 mm | 390 × 567 px |

不加入方形照预设。前三项沿用当前项目；大一寸物理尺寸参考[广东省因公赴港澳办证指引](https://www.gdhmo.gov.cn/bsdt/txzhqz/content/post_73689.html)，像素按300 PPI换算，属于本产品的默认输出，不等同于所有办事系统的电子照片要求。预设只定义尺寸，不代表已满足某种证件的全部审核规则。

### 自定义像素规则

- 输入实际宽、高，仅支持px，不再把宽高解释为比例，也不展示未经确定的毫米尺寸。
- 两个值必须是正整数。当前浏览器原型为控制生成资源消耗，单边不超过6000px，总像素不超过2400万；字段无效时在原处显示原因并禁用「使用此尺寸」。
- 成片按输入的精确像素输出，例如600×800，不改写为900×1200等“等比例近似规格”。
- 旧比例草稿按原输出读取；重新打开尺寸选择时带入对应实际像素，明确确认后再转为新的像素字段，不静默改变旧结果。

## 参数、制作与异常

| 场景 | 行为 |
| --- | --- |
| 选择目标 | 仅更新草稿，不提前生成成片或改变原图；原图保持完整 |
| 取消尺寸抽屉 | 原尺寸、底色、照片与已有结果保持；输入错误不带回主页面 |
| 快速选择并开始 | 使用最后选择的尺寸、底色；按顺序保存，旧请求不能覆盖当前任务 |
| 制作中 | 本页显示制作状态，照片内扫描，主按钮「制作中…」；返回、换图、参数修改禁用 |
| 制作失败 | 保留照片和精确尺寸、底色；「查看失败原因」打开抽屉，「重新制作」使用相同参数 |
| 刷新 | 从已保存会话恢复规格；制作中的会话回到可重试确认状态 |
| 备份失败 | 「照片设置暂未能备份，请保持当前页面并继续。」保留内存设置，后续成功修改或制作前再次备份 |
| 更换新照片 | 确认另一张图才创建新草稿，默认二寸、蓝底，不继承旧输出或付款状态；调用方上下文保留 |
| 返回确认页后换规格 | 不再匹配当前目标的旧成片缓存失效，原图保留；不能把旧输出当作新规格保存 |
| 制作结果 | 保留尺寸、底色及手动构图能力。尺寸选择与确认页共用目录、像素自定义含义；只有结果阶段展示裁剪控件。结果页整体布局本轮不重排 |
| 专项采集 | 显示「采集规格由项目统一设置」，不开放个人参数；既有固定输出、付款与任务回传契约不变，未扩展为真实后台配置能力 |

## oil-ui-pro视觉规范与验收

沿用知拍浅蓝背景、深蓝标题、知拍蓝选中态和主按钮。尺寸组标题13px，当前规格12px，标签13px；不叠加大卡片。抽屉按分组和留白区分标准尺寸与自定义，不使用多余线条和阴影。

复用选项150ms状态反馈、上滑抽屉、实际照片内扫描；减少动态效果时关闭新增过渡与缩放。源码检查与实际画面分别验收，不自动操作浏览器或截图，不以测试通过代替视觉验收。

验收路径：

1. 三种照片来源进入确认页，尺寸入口单行紧凑，顶部返回不触发选图。
2. 更多尺寸选择大一寸后关闭不确认，原尺寸不变；再次选择并确认后回显大一寸，输出390×567px。
3. 自定义600×800px，确认、制作失败、刷新、重试后仍输出600×800px；空值、0、小数、过大尺寸不能提交。
4. 确认页及尺寸抽屉不出现照片裁剪、缩放；成片页原裁剪仍可使用。
5. 取消换图保留目标；制作中不能换尺寸；专项采集不开放个人规格。
