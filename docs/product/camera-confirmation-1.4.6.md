## 目标与主流程

用户确认原照片及目标规格后，一次完成制作。准备阶段可改参数；检测通过自动继续；制作阶段只等待；检测未通过查看配置项结果，制作失败直接理解原因，两者保留有效输入；结果阶段在同页比较两版并只购买一版；付款后自动保存所购照片，成功进入完成页。

拍摄／相册选图 → **证件照制作**（原照片、照片规格、底色）→ **选择演示场景**（原型）→ **检测抽屉** → 通过自动进入约5秒同页Loading → 选择原型制作结果 → 两版或一版成功进入同页双版本结果 → 选择普通证件照¥1.98或精修证件照¥9.80 → 单次解锁 → 自动保存到知拍相册 → 保存完成。整次照片失败或服务不可用进入对应原因抽屉。

从首页／搜索「证照规格」进入时，先选规格及底色，再点击「去拍照或选图」进入上述流程；所选参数直接带入，制作页仍可修改，不增加第二次规格或底色确认。制作前的布局、快捷三项、检测与规格来源保持；结果页按下方双版本规则执行。

当前是移动Web原型。检测、制作与付款均为模拟，未接入真实AI识别、制作或后台配置服务。两版使用同一原图、规格、底色与构图生成实际Canvas文件；普通版不额外处理，精修版目前仅轻量调整亮度、对比度与饱和度，不代表已验证真实精修模型或照片质量。相册、工具「制作一张」共用本流程；专项采集使用项目固定规格，成功后回传既有任务。

## 检测规则与门禁

原型配置位于 `src/domain/camera-detection.js`，当前版本 `prototype-1`。配置包含版本、检查项标识、文案与启用状态，用于说明后续后台配置的契约，不是已实现的管理后台。

| 默认检查项 | 拒绝场景     |
| ---------- | ------------ |
| 有人像     | 未检测到人像 |
| 单人照片   | 多人照片     |
| 无动物     | 动物照片     |

- 只显示和执行启用项。空配置、无版本、未知或重复检查项均阻止制作，按检测异常处理，不默认通过。
- 演示方式已于2026-10-20确认变更：场景只由正常流程内弹窗选择，不使用专用测试网页、URL参数或旧草稿内保存的默认场景。关闭选择弹窗不运行检测，不生成订单或结果。
- 通过后自动继续，不要求用户再次确认，也不增加「检测通过」中间页。
- 每次开始制作都重新检测。证明绑定草稿、原图和配置签名；更换照片、配置变化、取消或制作失败使旧结果不可复用。
- 取消会使本次异步结果失效；迟到结果不能开启制作。检测阶段不创建制作结果或收费订单。
- 检测服务异常、超时及配置错误提供重新检测入口，不能冒充照片内容不合格。重试先重新选择演示场景，再重新检测，避免演示固定在上一次失败。

## 配置式检测提示规则（2026-10-20用户确认）

检测项由后台配置，前端按配置和返回数据展示名称、启用项及结果，不从「无人像／多人／动物」等演示场景推导额外指导文案。

检测未通过抽屉仅展示：标题「检测未通过」、统一说明「当前照片不符合制作要求，暂时无法开始制作。」、原图及保留说明、检测明细和「返回调整」。删除额外原因段及其生成逻辑，不以通用原因兜底替代该段；旧草稿中的定向提示也不再展示或加入可访问描述。

照片制作失败、制作服务不可用及检测服务异常的实际原因仍显示。检测通过自动继续、未通过阻止制作、取消及返回保留输入的规则保持。

当前原型仍采用本地默认配置与场景模拟，默认三项仅用于演示；正式对接以后台配置及检测返回结果为准。本轮未建设后台、接入真实识别或扩展原型支持的检测项类型。

## 制作失败分类与恢复

| 类别         | 类型依据                                                                                     | 提示与恢复                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 照片制作失败 | 适配器明确返回 `PHOTO_MAKING_FAILED`，保存 `failureKind=photo`                               | 「制作失败」；直接显示实际照片处理原因，缺少原因时提示调整照片后重新开始；「返回调整」回到确认页 |
| 服务不可用   | `MAKING_SERVICE_UNAVAILABLE`、超时、刷新中断、渲染或未知技术异常，保存 `failureKind=service` | 「暂时无法制作」；说明稍后重新开始、无需换照片；「返回」回到确认页                               |

失败类别由结构化类型决定，不根据原因文字猜测。旧失败草稿缺少或带未知类型时按服务异常恢复，同时使用中性说明「本次制作未完成，请稍后再试。」；不沿用旧文案中的换照片指引，不将未知技术错误归因于用户照片。明确类型的实际原因保持。原型中的照片失败原因示例为清晰度不足，不代表已接入真实清晰度检测。

两类均沿用已确认的浅红结果区、深红图标与标题、实际原因优先、后置原图及保留说明。制作失败不显示检测清单，不新增页面或二次原因抽屉。关闭、遮罩、Escape和底部返回均恢复确认页，清理失败类型及旧检测证明，保留原图、尺寸和底色；再次制作重新检测。整次失败均不生成可解锁结果、收费订单或专项成功回传；部分成功与失败版重试按双版本结果页规则处理。

## 预览与页面层次

- 页面底色浅灰冷白#F5F7FB；照片展示区5∶7、#E9EDF3灰底，按设备高度约170～214px宽，在页面居中；横竖来源共用稳定区域。
- 原图以contain完整显示，不裁剪或拉伸；空余处露出灰底。展示灰底与目标底色无关，不改变原图和成片像素。
- 预览无边框、阴影或外卡；下方12px为核对说明，再隔24px进入单个白色16px圆角参数区；不叠加卡片或分隔线。
- 页面左右20px，参数区内16px；分组标题14px，选项13px，辅助12px。底部48px双操作约40%／60%；次操作灰色文字与灰色描边，主操作知拍蓝。
- 场景选择沿用300px宽、16px圆角居中弹窗，18px标题、15px说明与纵向选项，选项触控高度至少44px；取消使用辅助灰色。短屏内容独立滚动，背景不可操作，焦点限制在弹窗。制作Loading与制作结果选择仍不可取消。
- 检测未通过与制作失败：固定标题行和滚动正文开头形成局部浅红结果区（#FFF1F2），左侧28px状态图标与18px加粗标题同为深红#B42332；15px统一阶段说明保留；仅制作失败追加实际原因（#402B32），检测未通过不追加原因段，不增加查看详情操作。白色辅助区后置56×78.4px原图、保留提醒及检测明细，仍完整显示照片；通过项辅助灰，失败项深红加粗。不叠加卡片、不全抽屉染红。
- 统一说明参与失败抽屉的可访问描述；仅制作失败追加实际原因，检测未通过不引用已删除的原因元素。不重复添加原因alert播报。长原因完整换行，位于可滚动正文而非固定标题区，底部48px恢复按钮（「返回调整／返回」）保持可见。该按钮自身定义知拍蓝底白字，避免Portal改变祖先后丢失样式。实际触摸、滚动与读屏仍需验收。
- 检测中、短暂通过和检测服务异常沿用原有白底、80×112px缩略图及状态展示；服务异常仍可重新检测，不表现为照片内容不合格。

4. 一版未完成时，该列显示「本版本未完成」、实际原因及「重试普通版／重试精修版」，示例原因「本版本未能完成制作，可重试或选择已完成的版本。」。成功版仍可选择与购买；重试只处理失败版，保留成功文件、选择与现有待付款身份，不重新制作两张。重试沿用约5秒不可取消Loading，之后明确选择「重试成功／重试失败／服务不可用」；提交期间不能购买。重试失败仍留在结果页显示该版原因，不覆盖成功版或跳到整次失败抽屉。
5. 文件显示失败使用「照片暂未显示」「重新加载」，重新读取当前文件，不当作制作失败。共同比较区下方为「放大对比」。错误就近显示，正文自然增长与滚动。
6. 底部固定一个48px主按钮。无选择时禁用并显示「请选择一个照片版本」；选普通版为「解锁普通版 ¥1.98」，选精修版为「解锁精修版 ¥9.80」。选择写入中为「正在选择…」；付款待确认时为「查询解锁状态」；保存中为「保存中…」；已付款但保存失败为「保存到知拍相册」，仅重试保存。

## 付款、保存与完成页

| 阶段 | 文案、行为与保护 |
| --- | --- |
| 选择版本 | 版本ID、名称、整数分金额与对应输出文件一起确定。普通版198分、精修版980分；付款抽屉为「确认付款 ¥1.98／¥9.80」 |
| 付款取消后改选 | 先将旧待付款收据以取消状态归档，并将新选择与文件放在同一持久化事务；失败保留旧选择与收据。再次付款使用新交易ID |
| 付款结果待确认 | 「查询解锁状态」查询同一订单，不另起交易；冻结版本、文件与金额，不能换版或重试另一版 |
| 付款或查询成功 | 自动把所购一版写入知拍相册；订单、所选版本与相册照片保持关联，不保存另一版 |
| 保存失败 | 「保存未完成，已解锁的照片已保留，请重试。」；留在所购成片，按钮「保存到知拍相册」只重试保存，不再次付款 |
| 保存成功 | 进入「保存照片」完成页，显示「保存成功」「照片已保存到知拍相册」，所购照片、版本及规格；「保存到设备」发起设备下载，「查看照片」查看所保存照片；「返回相册」回相册，工具／冲印来源为「继续使用」并按既有契约回传 |
| 完成后 | 同次制作不再购买另一版；订单与已保存照片保留。设备下载不等于已写入系统相册 |

## 结果页返回与交易保护

| 状态 | 返回行为 |
| --- | --- |
| 未解锁 | 「返回并重新制作？」；说明「返回后将丢弃本次制作结果，原照片和设置会保留。」；「继续查看」取消，「丢弃并返回」只清本次输出 |
| 待付款 | 旧收据关闭归档与输出／交易清理在同一事务完成；重做使用新交易，不复用旧权益 |
| 丢弃写入失败 | 保留两版与原交易，留在弹窗提示重试，不静默返回 |
| 付款结果待确认 | 查询原订单，保留冻结的版本、金额与文件 |
| 已解锁、未保存 | 先保存再退出；失败留在所购成片重试保存，不重复收费 |
| 已解锁、已保存 | 正常退出，保留相册照片和订单，不能返回另一版购买 |
| 制作重试／选择写入／付款／保存中 | 锁定返回和重复提交；放大查看层的返回先关闭查看层 |

## 异常与恢复

- 尚未选择演示场景时刷新，恢复未制作确认页；不自动选择或继续检测。旧草稿保存的模拟场景不再生效。

- 检测中刷新不伪装继续后台识别，恢复「检测暂未完成」并允许重试；检测拒绝草稿恢复统一说明和配置项结果，不展示旧定向原因；检测服务异常草稿仍恢复实际异常原因。
- 制作中刷新转为制作中断原因抽屉，保留原图与设置。失败草稿恢复原因抽屉。
- 等待结果选择的草稿只有检测证明仍有效时才恢复选择弹窗；旧草稿或配置变化必须重新检测，不能直接生成结果。
- 双版本刷新恢复两版文件、失败原因与选择，不自动预选。失败版重试中刷新保留成功版，未完成版恢复为可重试失败，不无限等待。
- 历史已付款／待查款单成片继续保留原文件、实际像素与订单金额，不迁移为新价格或另一版本。常规规格的旧未付款单成片可以保留原输出并补配双版本；未知、不支持的未付款旧规格回到受支持规格确认，不提供自定义规格。
- 旧 `camera=processing` 链接兼容恢复确认，不挂载独立制作页；设置备份失败保留内存内容并说明备份问题。
- 文件选择取消、重复点击、迟到任务及订单写入失败，不覆盖当前照片或静默越过制作步骤。

## 原型测试与验收

在正常「证件照制作」页面点击「开始制作」，直接从弹窗选择五种检测情况，无需离开当前流程。选择后检测约1.8秒，通过自动进入约5秒制作Loading，再由用户从原型弹窗选择「两版均成功／仅普通版成功／仅精修版成功／照片制作失败／服务不可用」。取消场景选择保留原图与设置；检测异常可点击「重新检测」重新选择。场景不通过URL或旧会话默认指定。均为原型模拟，不执行真实识别。

1. 拍摄、手机／知拍相册进入后不要求裁剪；参数只在制作前调整，换图取消保留输入。规格入口的九项、初始底色、用途名称与输出像素带入后仍可编辑，直接继续原流程；无二次规格确认。
2. 点击开始制作先出现五种场景弹窗；取消、重复点击、过期选择和浏览器返回不运行检测、不丢失设置。选择后检测项随配置展示；拒绝与异常不进入制作，取消后的旧结果不触发后续任务。
3. 通过自动制作；制作和结果选择不可取消；两版或一版成功进入无预选的双版本结果，检测未通过只显示统一说明和配置项结果，制作失败显示实际原因及辅助照片；照片失败显示蓝色「返回调整」，服务不可用显示蓝色「返回」；均保留原图和参数。
4. 顶部返回退出、重拍返回取消，不能出现相机与确认页互返；设备流正确释放。
5. 未付款返回只丢弃输出、重做不复用收据；初始无预选，两个价格与对应文件一致。部分成功可购买成功版，或重试失败版并保留成功版。
6. 改选先原子归档取消的待付款收据，待查款／已付款后锁定版本、文件与金额；查询同一订单。付款后只保存所购一版并进入完成，保存失败只重试保存；刷新与返回不重新出售另一版。
7. 深色对比层保持同位置、同步缩放与移动；外壳缩放下拖动坐标正确。实际尺度、拖动手感、长原因滚动与读屏待人工验收。
8. 专项固定输出与任务回传、独立精修¥2及工具／冲印调用关系保持。
