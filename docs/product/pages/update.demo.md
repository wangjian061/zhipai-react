# 全局强制更新演示

本页由桌面工作区顶部「全局演示」进入，独立展示强制更新过程，不属于知拍首页正文、通知中心筛选或某项照片业务。当前仅为内存模拟，不调用商店、不下载或安装App，也不改写真实任务和付款事实。

## 发现新版本

手机内升级覆盖层显示下载图标、标题「发现新版本」和「请更新至最新版本后继续使用知拍。」。已确认策略是每个平台、每个渠道的正式新版已经可获取后，该渠道所有旧版必须更新，不能改成只有低于最低版本才强更。

仅开发完成、提审、审核通过但尚未发布，不触发无包可取的拦截。原型Git日期版本、后台单独部署、需求迭代号或其他平台版本不触发本端升级；高于已发布版本的内部包也不能被要求降级。

## 更新内容

覆盖层展示「更新内容」，当前示意文字为「以当前平台、当前渠道的正式发布说明为准」。正式产品应取该平台该渠道有效发布说明、版本与构建标识，不预填三端相同版本号或虚构已经发布。

普通版本公告可以在通知中心告知，但升级检查与消息已读分别管理；关闭推送、滑掉通知或读过公告都不能解除更新要求。版本接口、有效策略缓存和正式发布后消息生成机制仍未接入。

## 去更新与重新检查

主按钮「去更新」，说明「从更新渠道返回后重新检查版本」。手机内无取消、稍后或跳过，用户可从系统离开App；去过商店只说明尝试更新，必须核对实际安装版本后才决定恢复业务。

当前按钮仅标记已点击并提示在左侧选择升级结果。工作区可演示发现新版、入口失败、仍旧版和模拟完成；模拟完成退出演示，不表示真实安装已完成。外层「恢复默认」是评审控制，不应还原为App允许跳过强更的业务按钮。

## 入口失败与仍为旧版

入口失败标题「暂时无法打开更新入口」，说明「更新尚未完成，请重试打开更新入口。」，主按钮变「重试打开」。返回后仍旧版则说明「尚未检测到已安装的新版本，请完成更新后继续。」，仍保留去更新。

两种情况都不显示更新成功，不清空任务或自动重复付款。查询失败不等于发现新版本，不能凭一次失败虚构强更；已有有效策略与离线重试如何衔接仍需技术方案明确。某设备不能安装新版的兼容及支持方式也未确定，不伪造可解决流程。

## 安全节点与恢复业务

启动及后台返回检查适用版本，旧版不启动新的业务操作。正在拍摄、付款或提交时遵守不打断：先保存照片、有效输入及已发起交易，回可恢复安全节点再要求升级，不能抢焦点或丢弃已付结果。

新版确认后按账号权限恢复原业务，不替用户重新拍摄、付款或提交。演示切入也受工作区忙碌保护；恢复默认、离开上下文或退出工作区释放会话。正常业务强更、商店入口和真实原生生命周期尚未接入。
