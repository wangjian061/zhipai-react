# 更换背景 · 选照片

这是更换背景的第一步，用于更换已有证件照的照片底色。从首页进入时没有候选照片；从相册照片详情进入时展示该张照片，仍需用户点击下一步，顶部返回原详情。

## 导航与步骤

顶部为统一返回、更换背景标题；三步进度只显示当前阶段，不可点击跳步。顶部返回退出工具并回来源，不承担内部上一步。

## 选择照片

未选时显示主题小白熊、选取一张照片，底部只有“选取照片”。已选时展示照片和真实文件信息，底部改为中性“更换照片”与主操作“下一步”，原来照片下方的换图入口移除。5∶7浅灰预览区完整等比显示原图，展示框不会裁剪或拉伸文件。

## 照片来源

知拍相册、手机相册。只选一张；手机来源的技术范围为30MB以内JPG、PNG、WebP，读取失败保留原照片并重新选择。选择抽屉固定标题、来源和底部“使用这张照片”，仅照片列表滚动。取消不替换当前照片；确认只带回候选并停留第一步，不打开相册编辑。

## 选图后操作

同图重新选择保留有效设置；确认另一张照片清除未受付款保护的旧产物。点击下一步后需要通过单人正面人像证件照检查。点击下一步才开始检查，不在选图完成时自动检测或前进。后续设置与完成页不另设换图入口，需要换图通过上一步返回这里。

## 照片检查

需要通过单人正面人像证件照检查。点击下一步才开始检查，不在选图完成时自动检测或前进。原型在当前流程内人工选择通过／不通过／异常，照片内显示轻蓝扫描，状态文字在照片下。通过自动进入背景颜色；未通过留在本页，“下一步”禁用，可查看原因或更换照片；异常保留重新检查。关闭场景选择不算通过，检查中两底部按钮暂禁用。

## 返回与恢复

顶部返回来源页面；抽屉打开时先关闭抽屉。选图取消保留当前照片和同次有效参数；已付款、待查款或已有成片的原单使用原快照恢复，不能被新候选覆盖或重复收费。免费工具，不创建订单，不新增知拍相册记录，也不删除历史已保存背景照片。与独立精修的收费、人像细节处理和相册交付不同。
