# 冲印照片 · 裁剪照片（2026-11-20 合并至「冲印预览」抽屉）

2026-11-20 起，「冲印照片」不再于选图后强制跳转到独立全屏裁剪页；固定一寸 `5∶7` 手动裁剪能力直接合并进「冲印预览」上滑抽屉的 **`手动裁剪`** 分段页内（保留旧 `view=crop` / `?print=crop` 路由兼容入口并正常导出校验后的 `5∶7` 裁剪文件）。

## 固定比例裁剪

固定一寸5∶7裁剪框，支持拖动、双指缩放、桌面滚轮和缩放、水平、垂直三项滑杆，不支持自定义比例和宽高。任意比例照片在进入「冲印预览」抽屉时先按默认 `5∶7` 居中适配，用户可在 `手动裁剪` 分段页随时微调；照片内容不受人像限制，原图不被覆盖。

## 裁剪确认

切换回「整版成品」、关闭预览或点「满意，去确认订单」时生成独立校验后的 `5∶7` 裁剪文件（商品页返回态与后续订单、两种排版均读取该裁剪产物）；生成中防重复，未获得有效裁剪文件不能进入确认订单。

## 失败与重试

裁剪失败留本页，保留调整；离页或换新照片后迟到结果不能污染新输入，不用旧结果冒充新文件。

## 返回与取消

返回或「上一步」回同一冲印工作页，保留此前有效输入和排版。预览抽屉通过「换一张」打开公共选图；取消不能绕过比例校验。
