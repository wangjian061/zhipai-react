# 收货地址

从本次冲印确认订单进入，选择一个地址用于配送。页面不承担更换照片、排版或付款。

## 地址列表

逐项展示收货人、联系电话、地区和详细地址及默认标记。未保存地址时显示空态并保留新增入口；读取失败与空列表区分。

## 选择与新增

点击有效地址选中并返回原确认订单；新增进入地址编辑，条目编辑保留对应地址身份，不创建新的冲印任务。

## 默认地址

默认标记只辅助选取，不代替用户当前选中地址。已有订单的配送快照不能被后来修改通讯录地址直接覆盖。

## 返回与恢复

顶部返回原订单阶段；取消选取不清掉原有效地址。照片、裁剪文件和版式在选择地址期间保留，表单失败不重做前序操作。
