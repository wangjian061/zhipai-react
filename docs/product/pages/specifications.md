# 照片规格

页面地址：`/?page=specifications`。由首页「照片规格」进入。先选本次制作规格及允许底色，再拍照／选图进入个人证件照制作；本页不裁剪已有照片，不提供自定义尺寸或官方审核承诺。

## 主题图、导航与返回

全幅浅蓝白规格主题图延伸到顶部，安静留白承托系统区，白色圆底返回、居中标题「照片规格」。主题图只有装饰作用，不承担选规格或拍照操作，没有底部主导航。

返回入口来源，缺失或非法来源回首页。列表位置保留，图片加载失败不能阻断目录与返回；真实系统安全区按平台处理，不将Web预览固定值当各机型标准。

## 常用规格宫格

「常用规格」为三列三行连贯宫格，每格图标、名称及独立数字尺寸，整格打开底色抽屉。长名称可自然换行，数值不截断；物理预设显示毫米，电子用途显示实际输出像素。

| 名称 | 宫格尺寸／用途 | 制作输出像素 |
| --- | --- | --- |
| 一寸 | 25×35 mm | 295×413 |
| 二寸 | 35×49 mm | 413×579 |
| 小二寸 | 35×45 mm | 413×531 |
| 大一寸 | 33×48 mm | 390×567 |
| 求职招聘 | 35×49 mm | 413×579 |
| 四六级考试 | 144×192 px／报名电子照 | 144×192 |
| 驾驶证 | 22×32 mm | 260×378 |
| 身份证 | 26×32 mm | 358×441 |
| 中国护照 | 600×800 px／全程网办电子照 | 600×800 |

顺序为宽×高。毫米和像素是不同字段，不互相冒充；求职招聘用二寸是产品默认，不是招聘行业通用标准。中国护照特指全程网办电子照，不写成33×48mm纸质规格；没有照片回执、官方审核、DPI元数据或受理保证。

## 选择背景

点击有效规格打开标题「选择背景颜色」抽屉，展示用途、物理／输出尺寸及「背景颜色」选项。每色有色块、名称和选中勾，不只用颜色区分。规格与制作页共用稳定ID配置，不按名称、寸数或比例写死底色。

当前本地配置：前五项蓝／白／红，四六级蓝，驾驶证／身份证／中国护照白。它们是示例配置，不是永久业务约束或官方全量标准。此前颜色仍有效则保留；唯一颜色自动选定；多色且旧色无效则清空待选，不静默换色。

多色有效提示拍摄后仍可调整，待选提示为当前规格选择底色；单色说明仅支持某色且已选定。无有效颜色显示「当前规格的背景颜色暂不可用，请选择其他规格或稍后再试。」，不补造备用颜色，主按钮不可用。

## 去拍照或选图

固定「去拍照或选图」仅在当前选择有效时可点，确认前再次按配置校验，直接进入现有相机，不加第二次规格／底色确认。传递规格稳定ID及底色，照片选中后进入个人制作，默认参数不能覆盖本次选择。

制作页仍可编辑规格与允许底色；重新拍摄／选图保留最新设置，取消设备选择保留原照片及参数。规格是个人新制作入口，与修改尺寸、专项项目固定规格各自独立；专项不会受这里残留参数影响。

个人制作完成后普通版¥1.98、精修版¥9.80，只解锁本次所选一版。这里不预选购买版本、不收费；独立精修¥2.00不属于此入口的价格或权益。

## 关闭、返回与无效参数

关闭、遮罩、Escape或系统返回先关选色抽屉，回目录原位置和触发项；关闭不建草稿、不付款、不跳相机。只有正文滚动，底部动作留安全区。刷新／前进回目录，不自动重开上次抽屉。

相机／制作顶部返回退出本次制作回规格列表；重拍中的返回只取消重拍回原制作。无效规格／颜色不生成自定义项，非法返回回首页；旧tool=spec兼容新目录。当前目录与处理含本地配置／模拟，不保证各受理方合规。
