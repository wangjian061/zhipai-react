# 首页

页面地址：`/?page=home`

首页帮助用户找到要办理的照片业务。专项采集是重点入口，同时提供个人证件照制作、现有照片处理、相册和扫码入口。用户在首页识别业务并进入对应流程；具体项目、照片、规格设置和付款由目标页面承接。

本页按手机画面从上到下分为：**顶部轮播、搜索、专项采集卡片、常用工具、底部导航**。点击任何入口后，左侧切换为目标页面自己的完整说明。

## 顶部轮播

### 展示什么

顶部是三张完整宣传图片，顺序为专项采集、证件照制作、照片精修；默认显示专项采集。图片内包含标题、说明、人物及操作提示，正常状态不再额外叠加文字或图标。

| 轮播内容 | 告诉用户什么 | 点击后进入哪里 |
| --- | --- | --- |
| 专项采集 | 新生入学、毕业生及行业协会会员有对应的机构采集服务 | 专项采集首页，继续选择具体项目；不预选项目或直接认证 |
| 证件照制作 | 可以为自己制作证件照，后续选择照片规格和底色 | 相机页，拍照或从相册选图，再进入证件照制作 |
| 照片精修 | 可以对已有的人像证件照改善细节和观感 | 独立照片精修的第一步「选照片」，不自动使用宣传图 |

### 如何操作

- 点击当前轮播图，进入这一张对应的业务；轮播图内的操作文字与整图使用同一个去向。
- 左右滑动切换，电脑键盘方向键也可切换。当前约每7秒自动切换，不新增一种业务入口。
- 用户正在滑动、鼠标悬停、键盘聚焦、打开选图层，或页面不可见、离开首页时暂停自动切换；系统要求减少动态效果时也暂停。
- 滑动结束不误触业务跳转。下一张图片加载成功后再切换，过期加载结果不覆盖后一次选择。

### 展示与异常规则

头图保持沉浸式，系统栏和灵动岛使用图片上方预留的安静背景；不额外加一条空白，不让标题、人物或操作提示与系统状态重叠。图片完整等比展示。

当前图片无法显示时，保留该业务的标题、图片失败说明及对应操作，用户仍可进入这一业务。宣传人物只用于表达业务，不作为用户已经选中的照片或实际采集合规示例。

## 搜索

### 展示什么

搜索入口显示「请输入搜索内容」，右侧为「搜索」。首页这一整块是进入搜索页的按钮；用户在独立搜索页输入关键词。

### 如何操作与返回

点击图标、提示文字或「搜索」，都进入 `/?page=search`，初次从首页进入不带关键词。搜索页负责输入、匹配结果、无结果与清空；顶部返回回到首页。

首页搜索用于查找**证照规格和照片工具**。寻找机构的采集项目，进入专项采集后使用项目搜索，两个搜索的对象不同。

| 用户想找什么 | 从首页怎样进入 |
| --- | --- |
| 一寸、二寸、简历照等照片规格 | 首页搜索，或常用工具中的「证照规格」 |
| 精修、换背景、裁剪、格式和体积工具 | 首页搜索，或直接点击对应工具 |
| 需要参加的学校、机构采集项目 | 点击「专项采集」进入专区，再查找项目 |

## 专项采集卡片

### 展示什么

卡片位于搜索下方，保持首页最醒目的稳定业务主卡。左上标题为「专项采集」，适用人群为「新生入学 · 毕业生 · 行业协会会员」，右侧箭头指示进入，下方为无文字的蓝白色采集主题配图。

### 如何操作与返回

整张卡片只有一个去向：专项采集首页 `/?page=collection`。标题、箭头、配图区域点击结果相同；不因点击某个区域而预选不同人群或项目。专区内再选择项目、核对要求并继续办理，退出专区回到首页。

### 和顶部专项轮播有什么不同

轮播承担宣传与多业务展示，会切换到个人制作或精修；专项卡片始终提供采集专区入口。两处进入同一个专区，不能各自接入一套不同采集流程。

卡片本身不轮播、不请求本人任务、不展示认证或付款结果。配图无法显示时，标题、适用人群和进入链接仍然保留。

## 常用工具

### 展示什么

工具采用四列两行，顺序固定。第一行：**冲印服务、照片精修、照片换装、证照规格**；第二行：**照片裁剪、更换背景、格式转换、修改体积**。

八格采用首页已确认的极淡连线宫格。后四项显示小号「免」角标，表示这四项免费；不因为页面名称都在「常用工具」中，就默认它们的输入、检测、收费和交付方式相同。

### 八个入口分别做什么

| 入口 | 解决的问题 | 选图与检查要求 | 收费及最终结果 |
| --- | --- | --- | --- |
| 冲印服务 | 将照片制作成实体背胶模切排版照 | 知拍相册或手机相册；不限制照片内容，只校验5∶7比例，不符时先手动裁剪 | 一版¥19.80＋运费¥10.00；只支持4大8小或8大，不加印，填写地址后配送 |
| 照片精修 | 改善已有证件照的人像细节和观感 | 知拍相册或手机相册；需要通过人像证件照检查，再选择一种底色 | 独立工具¥2.00；完成后自动保存到知拍相册，可查看前后效果 |
| 照片换装 | 更换已有证件照中的服装 | 已确认规则为仅知拍相册，仍需人像证件照检查；手机来源禁用待代码实施 | ¥2.00；选择服装后付款处理，完成后自动保存到知拍相册 |
| 证照规格 | 先明确要制作什么规格，再拍照或选图 | 首先进入九项规格目录；选规格及允许的底色后进入相机，不是现有照片编辑步骤 | 接入个人证件照制作；成片普通版¥1.98、精修版¥9.80，本次只解锁一版 |
| 照片裁剪 | 调整取景和照片规格 | 知拍相册或手机相册；不做人像内容检查，使用现有预设规格，不提供自定义 | 免费；生成裁剪结果并下载到设备，保留原照片 |
| 更换背景 | 更换人像证件照底色 | 知拍相册或手机相册；需要通过人像证件照检查，再选择背景 | 免费；处理结果下载到设备，不新增知拍相册记录 |
| 格式转换 | 满足JPG或PNG文件格式要求 | 知拍相册或手机相册；不做人像内容检查 | 免费；转换后的文件下载到设备，不改变原文件 |
| 修改体积 | 满足上传文件的KB／MB上限 | 知拍相册或手机相册；不做人像内容检查，设置文件体积上限 | 免费；输出JPG并下载到设备，保持像素尺寸，不保证某个精确文件大小 |

以上价格用于解释当前已确认的业务规则，不在本次调整中向手机首页额外添加价格标签。换装手机来源的文档与代码差异需明确保留，不能以本样例宣称已经禁用。浏览器下载不能直接等同于原生App已写入手机相册。

### 需要明确的区别

- **精修与换背景**：精修处理人像细节，并在第二步选择底色；换背景只承担底色处理，收费和结果去向也不同。
- **裁剪、格式转换、修改体积**：分别处理构图／规格、文件格式、文件体积，不相互替代。调整KB上限不能悄悄改小像素尺寸。
- **证照规格与照片裁剪**：证照规格是新制作的前置入口；裁剪用于处理一张已有照片。规格目录和裁剪均不提供自定义照片尺寸。
- **独立照片精修与个人制作精修版**：前者从已有照片开始，当前¥2.00；后者属于个人制作双版本结果中的精修版，当前¥9.80。两者是不同业务，不能混用订单、价格和购买权益。
- **冲印与电子文件工具**：冲印购买实体产品，需要排版、地址和配送；电子工具交付文件或保存相册。

### 从首页进入后的第一步

冲印和六项照片处理工具，点击后直接进入对应工具的「选照片」阶段。首页不预先弹出选图、不直接开始检测，也不使用宣传图作为用户照片。

1. 未选图时，底部只有「选取照片」。
2. 选图后停留第一步，底部为「更换照片＋下一步」。
3. 点击「下一步」才执行所需的人像检查、冲印比例校验，或进入设置。
4. 检查通过直接进入下一阶段；不通过留在当前步骤，保留重新操作的入口。

证照规格单独进入规格目录，随后选底色、进入相机；可选底色随规格配置，不按规格名字写死。用户取消选色留在目录，原有个人制作页继续承接已选参数。

各目标工具的顶部返回负责退出工具并返回来源；底部「上一步」负责内部步骤回退。完整设置、付款、处理、失败与结果交付，在对应二级页面自己的说明中展开。

## 底部导航

### 展示什么与进入哪里

底部为「首页、相册、我的」三个主导航，以及独立的「相机」「扫码」入口。首页为当前选中项。

| 入口 | 用途与目标 | 本页需要交代的边界 |
| --- | --- | --- |
| 首页 | 回到当前首页 | 保持当前导航选中状态，不发起照片业务 |
| 相册 | 查看知拍相册中的照片 | 照片查看、管理和详情工具由相册页说明 |
| 我的 | 进入个人中心 | 登录、账号安全、订单等从个人中心继续，不在首页直接展开 |
| 相机 | 进入个人拍摄／相册选图流程 | 记录首页为来源；实际权限与取消恢复由相机页承接 |
| 扫码 | 进入扫码采集 | 记录首页为来源；机构码、学信网码去向及获取码帮助由扫码页承接 |

### 滚动与遮挡

标准手机首屏完整展示常用工具，工具卡与底部菜单保持间隔。字体放大或可用高度不足时，正文可自然滚动，最后一行也能完整移到菜单上方；菜单保持可操作。

菜单后方无内容侵入时为透明背景；实际有内容经过菜单后方时，才显示底部较实、向上渐透明的承托层。它用于维持按钮辨识，不遮掉工具内容，也不增加一整条固定实色底栏。

## 本页交付与实现说明

- 首页不放通知、审核结果等演示按钮；通知相关演示归属通知中心，登录异常归属登录页面。强制更新放在工作区的全局入口，独立于首页业务正文。
- 首页的所有入口、文案与来源返回以已确认产品规则及当前实现共同核对；发现差异标记待整改，不用代码中的旧行为覆盖已确认规则。
- 当前照片检查、AI制作、付款及物流仍为原型模拟；图片读取、裁剪、转换、压缩和浏览器下载存在本地能力。进入某个入口不代表真实服务已经接入。
- 研发还原时逐项核对三个轮播去向、两种搜索对象、稳定专项卡、八工具差异、正确首步与返回、免费角标及底部净距。
