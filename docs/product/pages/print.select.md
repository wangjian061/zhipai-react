# 冲印照片 · 选择照片

冲印第一步取得一张照片。支持人像或其他内容；与照片精修、换装不同，本业务只校验可用文件及排版需要的比例。

## 选择照片

未选时底部只有选取照片；确认照片后仍在第一步，展示原照片与文件信息，底部为更换照片＋下一步。删除照片下方重复换图入口，不自动进入排版。

## 照片来源

知拍相册、手机相册均开放，只选一张。抽屉固定标题、来源及使用这张照片，只有照片列表滚动。取消不换图；从相册照片详情进入显示已选状态，顶部返回原详情。

## 比例检查

点击下一步才校验5∶7，一寸25×35mm与二寸35×49mm同为该比例，允许常见像素取整误差。符合直接进入选排版；不符合进入固定比例裁剪。不是人物也允许冲印，不增加人像检测。

## 返回与恢复

顶部返回退出冲印到来源，第一步无上一步；原照片不覆盖。已有待查款或已付原单从原快照恢复，不被新候选替换，不为重试另建收费单。
