# 输入验证码

页面地址：`/?page=account&account=code`。从手机号登录、第三方绑定或找回密码成功取得验证码后进入，同页依据用途决定登录或继续重置。没有有效挑战直接打开此地址会回手机号步骤，不凭URL生成验证授权。

## 返回与验证码接收号码

顶部返回用途对应的号码步骤：登录回手机号、绑定回绑定手机号、重置回找回密码。品牌下标题「输入验证码」，说明验证码已发送至脱敏号码；号码与当前挑战必须一致，不能使用另一个号码已通过的结果。

返回保留同次号码和协议选择，不延长挑战有效期。页面保持已确认单屏目标，键盘打开和大字体仍待真实设备验收，不能用源码禁滚动证明输入与按钮绝对无遮挡。

## 六位验证码输入

界面显示六格和「6位验证码」，实际用一个输入承载粘贴、系统自动填充及焦点，过滤非数字、最多六位。进入时聚焦，未满六位主按钮不可提交；编辑清除旧错误。

错误显示「验证码不正确，请重新输入」，过期显示「验证码已过期，请重新获取」。当前提示「原型演示验证码：123456」，不发送真实短信；演示不能作为生产认证、安全校验或自动填充验收证据。

## 重发倒计时

发送后60秒内显示剩余秒数，不可重复发送；到时显示「重新发送验证码」。重发成功清空旧输入并使用新的挑战，5分钟有效。冷却内返回再获取沿用原挑战，不刷新有效期。

失败保留当前可恢复输入并显示实际错误，不能在发送尚未成功时宣称新码可用。离开账号流程停止倒计时并清理临时状态，迟到验证结果不污染新号码或其他账号。

## 登录、验证并继续与更换手机号

普通登录及绑定用途主按钮为「登录」，成功建立本地会话，绑定用途同时关联选定第三方，然后返回原业务。重置用途为「验证并继续」，只授予当前号码一次重置资格，进入新密码页，不自动登录。

「更换手机号」回对应号码页并清除验证码、挑战、错误、倒计时及重置授权；旧码不能继续用。忙碌时禁用重复提交和返回。验证成功不自动创建任务、付款或提交照片；扫码交接仅继续原认证阶段。

## 协议与授权

本页不另放协议复选框或第三方入口，沿用同一次号码流程已作出的同意，验证仍核对它。需要重新阅读可返回对应号码页；不把此说明冒充本页可点击协议入口。离开整个流程重新进入须重新同意。
