# 通知中心

页面地址：`/?page=collection&view=notifications`。从个人首页铃铛、专项首页或服务中心进入，集中查看本人可接收的系统、项目和采集结果。页面按[第二阶段完整需求](../collection-stage2-1.4.6.md)实现本地原型；真实发布与系统推送尚未接入。

## 通知中心头部

保留「通知中心」「项目动态 · 采集进度」及现有配图，左上返回进入前的页面；从个人首页铃铛进入时返回个人首页。通知页不展示专区底部菜单。进入消息、任务或公告后返回，恢复原筛选、列表位置与消息焦点。

## 全部、系统、项目、采集

四个筛选中「全部」不算通知类别，切换不改变已读和任务。

| 类别 | 来源 | 点击去向 |
| --- | --- | --- |
| 系统 | 后台按受影响平台／人群人工发布，原型为本地配置 | 完整公告正文 |
| 项目 | 后台选项目、人群填写内容，原型为本地配置 | 完整公告正文，再按需查看项目 |
| 采集 | 本人的五类采集结果 | 原任务最新详情 |

人工公告可勾选同时发送手机提醒，默认关闭；不增加开放／截止自动定时通知。

## 消息卡片与历史

白卡按图标、标题、未读点、时间、项目／来源、摘要展示，整卡点击。消息按发生时间倒序；历史内容不随当前任务覆盖。

| 采集结果 | 站内记录 | 手机提醒规则 |
| --- | --- | --- |
| 制作失败、审核未通过 | 保留 | 重要消息 |
| 采集完成，项目无需上网 | 保留 | 重要消息 |
| 采集完成，项目需上网 | 保留 | 等上网结果，不提醒 |
| 上网完成、上网失败 | 保留 | 重要消息 |
| 制作中、待提交审核、审核中 | 不生成 | 不提醒 |

同次结果不重复生成，新一次提交／重试的结果另留历史。旧失败后完成，两条都可查看，旧消息仍进入最新完成任务，不恢复旧重拍／付款操作。过时待发提醒停止，历史不补推。

## 查看消息与返回

只有成功打开原任务或完整正文才标已读。收到、关闭提醒，自动更新当前任务，登录取消，目标不存在及正文失败均不算已读。已读仍保留，不提供一键已读、删除、清空。

本地历史与已读按账号隔离保存于本浏览器；账号切换不显示前账号内容。正式App由接口返回授权消息和稳定事件ID，不能照搬本地存储充当权限服务。

项目公告先读正文，再点「查看项目」，从项目返回原公告，再返回消息列表。目标失效说明无法查看，不跳其他任务或项目。通知点击不自动认证、付款或提交。

## 空列表与读取失败

未登录显示「登录后查看你的通知」及「去登录」，登录后回本页。读取中显示「正在读取通知…」。全部为空显示「暂无通知」，筛选为空显示「暂无此类通知」。

通知历史或采集结果读取失败展示明确错误和「重新读取」，保留可读历史；失败不能当空列表，重试不创建重复消息。写入已读失败保留未读。

## 手机提醒与升级消息

用户正在对应任务时只更新结果，普通页出现重要消息可点击的轻提醒，拍摄／付款／提交与已打开抽屉时不插入、不抢焦点。手机通知不包含姓名、证件号、照片或详细失败原因；系统权限关闭不影响站内消息和采集。

本地轻提醒可演示；真正手机推送、设备归属与发送重试仍由正式App／服务端实现。强制更新归属顶部「全局演示」，不依赖通知已读或推送权限。

## 本页演示与实现边界

左侧场景提供五类结果、系统与项目公告、空消息、读取失败及正文无法读取。场景为隔离内存，不写真实消息或已读；旧消息打开同一演示任务的最新状态。

普通页面已接入本地历史、已读、公告与任务去向。后台人工发布、真实推送和多设备同步未接入。依据：[模块规则](../collection-notifications-1.4.6.md)、[消息适配器](../../../src/domain/collection-messages.js)、[通知组件](../../../src/components/CollectionNotifications.jsx)。本次本地修改待用户验收。
