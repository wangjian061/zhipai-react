# 明信片制作 · 商品与定制

首页「照片纪念品」左侧进入，也可从照片详情或个人中心携带当前照片进入。商品页展示款式和参数，构图在「定制预览」抽屉进行；旧模板目录地址归一到本页，顶部返回实际来源。

## 款式与商品参数

商品图在白底上展示纸面与厚度。可横滑选择校园来信、生日祝福、毕业留念、旅行邮记、日常问候和相聚留影六款。切换后，官方商品图与定制预览采用同一款模板。商品图中的人物为3D样片，商品和预览图片不叠加文字角标。

模板下方的商品卡左侧显示「定制明信片」，右侧标价 `¥10.00 / 张`。下方展示简介「上传一张照片，把毕业、旅行或相聚的瞬间做成明信片。下单前可预览并调整。」以及三行参数。

- 材质为「富士相纸」
- 尺寸为「六寸」
- 成品数量为「每单 1 张」

运费在确认订单中另列。

每款为横版3∶2，成品合成为1800×1200px。校园来信的照片放左侧，日常问候放右侧，其余四款放上方宽窗。每张定稿提供独立的透明照片窗口，由当前款式决定实际裁切位置。

## 当前明信片

「上传照片 · 预览效果」打开公共选图抽屉。知拍相册先点缩略图，再点「使用这张照片」。手机相册可选一张 JPG、PNG 或 WebP（≤30 MB）。主动点「制作一张」可进入现有相机，保存后点「继续使用」带回成片。确认选图后自动打开「定制预览」，取消或退出拍摄保留已有照片与构图。

## 定制预览

原图与模板读取时，画布显示「正在生成定制效果…」。读取失败在画布原位显示原因，可「重试」或「重新选图」。成品就绪后可直接拖动、双指捏合、用滚轮缩放或双击在 1× 与 2× 间切换，也可用缩放、左右和上下滑杆精调。缩放范围为 1–3×。左转、右转只作用于照片。抽屉内横滑可选六款模板，与商品页同步。切换时保留已就绪画布，新模板就绪后更新。「换一张」取消时回到当前预览，换图成功后新照片从默认构图开始。关闭抽屉保留状态。

## 下单

抽屉底栏「满意，去确认订单」按当前预览导出成品，进入[确认订单](keepsake.postcard.confirm.md)。返回商品页时可「继续预览」或「去确认订单」。订单「上一步」回到进入订单前的商品页或定制预览，并恢复原照片与构图。已付或付款未确认读取原单快照。
