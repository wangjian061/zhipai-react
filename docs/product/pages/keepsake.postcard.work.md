# 明信片制作 · 商品与定制

首页「照片纪念品」左侧进入，也可从照片详情或个人中心携带当前照片进入。页面直接提供商品选购和构图；旧模板目录地址归一到本页，顶部返回实际来源。

## 款式与商品参数

商品图在白底上展示纸面与厚度。校园来信、生日祝福、毕业留念、旅行邮记、日常问候共五款，横向选择后上方商品图与下方定制预览同步切换。款式图使用正式3D人物，商品和预览图片不叠加文字角标。商品价10元／张，六寸富士相纸；运费在确认订单中另列。

## 当前明信片

「选取照片」与「更换照片」打开常用工具同款抽屉。知拍相册先点缩略图，再点「使用这张照片」；「手机相册」选一张 JPG、PNG 或 WebP（≤30 MB）直接回本页预览。原图不要求是证件照。只有单独点「制作一张」才进入证件照制作，保存后点「继续使用」带回新成片并恢复当前模板。取消选取、读图失败或退出拍摄保留原照片和构图。选图与生成成品分开；仅在点击「下一步」时合成。

## 调整构图

选图后项目页按卡片可用宽度展示整张明信片，图下写「点击调整照片」。点击预览打开公共上滑抽屉，在照片窗口拖动或双指缩放，也可以使用缩放、左右、上下滑杆。「左转 90°」「右转 90°」只旋转照片，纸面、文字与装饰保持正向。旋转后可以继续移动和缩放，重置回到居中、1倍、0°。下单使用与确认预览一致的构图。点「完成」应用到原商品页，点关闭、遮罩或系统返回放弃本次调整。选图后切换款式沿用照片与适用构图，更换照片成功才重置构图，取消或失败保留原输入。商品示例与用户上传的图像分开。

## 下单

有有效照片才可点「下一步 · 填写收货地址」。按当前模板、原图和构图生成成品，再进入[确认订单](keepsake.postcard.confirm.md)核对地址与费用。生成失败留本页可重试；订单确认返回恢复构图，已付或付款未确认读取原单快照。
