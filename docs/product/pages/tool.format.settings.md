# 格式转换 · 处理设置

上一步已确认照片；本页只调整目标格式并完成当前处理，不在这里重新选图。

## 照片预览

居中完整显示当前照片及必要文件信息，照片适应5∶7浅灰区域，最大250px宽。预览框不决定文件尺寸；处理光带只作用于实际照片，不覆盖整块预览区域。

## 处理设置

展示源格式及JPG、PNG两个目标选项。选择后生成对应结果，有有效产物才允许保存。扩展名与文件真实类型一致，像素尺寸保持原值；切换格式后不保存上一个格式的旧产物。

## 付款与处理

本工具免费。点击保存到设备生成或复用本次有效产物并发起浏览器下载，不创建收费订单、不写知拍相册；浏览器只能确认调用下载，不能证明已写入手机相册。处理时相关操作禁用，状态文字放照片下方，避免重复点击。格式转换处理文件类型，不承担裁剪或指定KB大小的职责；需要文件体积上限时使用修改体积。

## 底部操作

固定左侧“上一步”返回本工具选图，保留同一照片的有效设置；右侧为“保存到设备”。未满足必填设置或没有有效结果时主操作禁用。确认另一张照片需要回到选图重新走流程，当前页不提供第二个换图入口。

## 结果与异常

成功后发起下载并进入处理完成页。失败保留当前照片、设置和已经生成的产物；能复用结果时仅重试交付，不重新处理或收费。文件生成失败与下载调用失败区分；未发起成功不写成已保存。
