# 专项采集服务中心

页面地址：`/?page=collection&view=services`。通过专区底部「服务中心」进入，自助查看采集帮助，无法解决时由知拍客服统一受理并协调机构。

## 服务中心头部与导航

保留「服务中心」「采集帮助 · 客服支持」、现有客服配图和圆形返回；返回退出专项到首页。底部仍为专项列表、采集记录、服务中心及扫码。

正文顺序固定：通知中心入口 → 联系知拍客服 → 九项采集帮助。共用一个自然滚动区，底部避让菜单。无任务、未认证、未登录以及个人记录读取失败都不阻断通用帮助和联系。

## 通知中心入口

显示「通知中心」「系统通知与项目动态」。进入通知中心并记录本页为来源，返回恢复位置。服务页不堆消息、不放通知演示按钮；帮助不生成业务通知。

## 联系知拍客服

卡片显示「联系知拍客服」「采集问题统一受理与协调」及「联系」。点击打开共用邮件抽屉，不要求先认证、付款或创建任务。

从任务页联系客服时带当前项目名与客服号；号码未生成如实说明，不猜造，也不将客服号当访问授权。姓名、资格、名册问题统一由客服协调机构，用户不用选择机构受理渠道。

## 帮助内容

九项标题逐行展示。学信网图像采集码条目直接打开[学信网图像采集码获取教程](https://www.zhipai.com.cn/h5/bystxcj.html)，Web原型新标签打开并保留服务页，原生端由内置网页承载；其他八项沿用统一上滑抽屉，固定标题、关闭及「我知道了」，仅正文滚动，关闭恢复原列表位置和焦点。

| 标题 | 要说明的处理方式 |
| --- | --- |
| 如何找到需要参加的采集项目？ | 分类／搜索查找，核对名称、时间和要求，未开放不新办 |
| 如何获取机构／院校二维码？ | 机构院校提供，查采集通知，保存或扫描，未找到联系客服协助核实 |
| 如何获取学信网图像采集码？ | 直接打开[学信网图像采集码获取教程](https://www.zhipai.com.cn/h5/bystxcj.html)，不再显示本地步骤 |
| 身份信息无法匹配或资料有误怎么办？ | 先核对项目／方式／资料，仍有问题由客服协调，不重复建任务 |
| 支付后没有继续采集，怎么办？ | 回原任务核实付款，结果未知先查原单，不重复支付 |
| 照片制作失败怎么办？ | 查原任务原因与允许的操作，保留任务和付款 |
| 照片审核未通过怎么办？ | 看审核意见，按项目允许范围重拍提交，无法继续联系客服 |
| 上网失败需要重新拍照吗？ | 查看原因并联系客服，不无条件重拍、重新付款 |
| 采集完成后如何保存照片？ | 在可保存任务保存，失败重试保存，不重做或重付 |

两类码的详细步骤与扫码页共享同一帮助源，不维护不同版本。不补造审核时限、服务时段、退款承诺或项目例外权限。

## 邮件联系

服务中心与原任务共用「联系知拍客服」抽屉。仅有效任务来源展示项目和客服号；无任务说明可直接描述项目与问题。展示、复制和外跳都读取同一有效配置邮箱，当前本地候选为`zpai_service@163.com`，正式发布前需核实。

底部「复制邮箱」为次操作、「打开邮箱」为主操作。点打开即外跳确认，不叠加第二次确认；关闭不外跳。复制实际成功才提示「邮箱已复制」，失败提示长按地址复制。

打开后保留来源，提示未打开可复制邮箱，邮件需由用户在邮箱应用中发送。浏览器无法可靠确认邮件应用是否打开或邮件是否发送，不提示已发送／已受理。正文不预填完整证件号或照片。

## 帮助及邮箱配置读取

当前九项帮助与邮箱由一个本地适配器提供；正式端后台维护，三端读共同配置，仅内容更新不要求App发版。读取中、读取失败、空内容和无有效邮箱区分；失败提供重读，无有效地址不生成邮件链接或补造备用地址。

本页左侧仅提供服务自有的九项帮助、读取失败、无有效邮箱和邮箱打开失败样例，样例不改真实配置、不打开邮件。真实后台、缓存生效、复制权限和三端邮件恢复待接入验证。
