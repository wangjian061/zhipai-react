# 采集任务详情

页面地址：`/?page=collection&view=detail`，完成状态沿用同一详情结构。由本类采集记录、具体项目的当前任务或通知进入。本页帮助用户核对采集人、项目、当前状态及下一步；打开原因、提交或客服抽屉时仍属于本页，不以一小段抽屉摘要替换完整说明。

## 选择拍摄方式

支付成功后在任务详情点「开始采集」打开「人像采集」抽屉。选前置或后置先关闭抽屉，再展示对应的站位指引。前置用支架固定手机，符合取景要求后自动拍摄；后置由帮拍人看提示，构图合适后按快门。只有勾选「下次不再提示」并点「知道了，开始拍摄」才记住本设备的该方式。关闭、遮罩或返回回到方式选择，取消不保存偏好。从相册选图直接选文件。

## 返回与当前状态

顶部右侧「客服」打开本次任务支持。返回先关闭当前抽屉；本类记录来源回原记录页并恢复进度筛选与位置，项目来源回原项目，通知来源回通知中心并恢复筛选与位置。旧任务链接按真实项目归属回项目；资料不可用时回有效分类或知拍首页。项目再回来源分类或独立搜索页，保留关键词和列表位置。

状态图标、标题和说明位于不透明白色主卡最前，按同一任务最新结果展示。状态标题统一近黑色`#1D1D1F`、说明统一深灰`#3F4248`；外层背景和图标保留原状态色。主卡使用不透明白色，不再透色或模糊后方背景。后台25／26都显示审核中，不增加内部工序；未知状态显示「状态待更新」，只查看与返回记录。

| 当前状态 | 用户看到什么及可做什么 |
| --- | --- |
| 待拍摄 | 身份已核对；开始拍摄，未付先支付原任务费用 |
| 证件照制作中 | 等待制作；返回项目，不重复发起制作 |
| 证件照制作失败 | 查看原因，按项目允许重新制作 |
| 待提交审核 | 制作成功但尚未提交；主动提交审核 |
| 审核中 | 等待处理；返回项目，不重复提交 |
| 审核未通过 | 查看审核意见，按开放规则重新拍摄 |
| 采集完成 | 审核通过，可保存照片；不等同于学信网上网完成 |
| 上网完成 | 后台确认已提交学信网，可保存照片 |
| 上网失败 | 查看原因并联系客服，不自动重拍、重提或再次付款 |

上述状态共享于记录、项目任务和通知。上网状态的生产枚举尚需服务端核对，原型字段不是正式协议；页面中的审核时长属于当前原型文案，不能扩展成机构承诺。

## 采集照片

照片与状态共用一个不透明白色主卡，完整等比居中，最大高240px、宽224px，不裁剪或拉伸。待拍摄显示带「拍摄参考」标记的参考人像，不写入本人记录；有实际成片时展示该任务照片。

照片无法读取时保留说明及可用重新读取，不以参考图冒充实际照片。制作中显示对应处理状态，不据动画认定已接入真实AI。标准402×874常规内容以首屏完整为目标，长资料、大字与异常内容仍在原正文滚动，固定主操作不覆盖最后一行。

## 本次采集信息

照片下虚线后为一个连续的左右列表：客服号、姓名、证件信息、适用的学号／工号／认证编号、项目名称、所属机构。标签在左、值在右，值统一13px，仅客服号加粗；没有折叠、补充信息或本页复制按钮。

身份证／护照等已有完整或脱敏号码按原值展示，不重复同号末四位；仅有lastFour则明确「证件号后四位」。学号、工号不得充当身份证号，旧记录方式未知时使用「认证编号」。缺值显示「未提供」，客服号缺失为「未生成」，不补造六行。存量补充字段兼容保留，但本页不再编辑。

## 底部办理操作

固定主按钮按上表状态变化，发起前再次检查当前账号、任务、项目开放与付款事实。制作失败、待拍摄、待提交、审核未通过受原项目开放校验；已付任务重拍不重复收费。处理中禁用重复动作，离页后的迟到结果不能写入其他任务。

保存照片仅在提供此动作的完成态执行，失败可重试保存或咨询，不重新制作或购买。浏览器下载与原生写入手机相册分别验收；进入详情、查看通知或打开客服都不等于已经提交或保存。

## 失败原因

「查看未通过原因」或「查看失败原因」打开上滑抽屉，固定标题、当前项目、原因标题及完整实际原因，长正文独立滚动。没有详细内容时显示「暂无详细原因，请联系客服核实」，不根据失败类别生成虚构的照片问题。

关闭恢复详情，保留照片和权益。审核未通过与上网失败不同：前者按允许动作重拍，后者联系知拍客服协调，不把旧失败通知中的操作重新施加给已经完成的任务。

## 提交审核

待提交态点击「提交审核」，抽屉展示本人照片、姓名、项目与对应编号，说明「核对照片及本人信息后提交审核」。只有任务仍待提交、照片存在且项目允许才可「确认提交审核」；忙碌时显示正在处理并阻止重复提交。

取消或关闭停在待提交，不改成审核中；失败保留原资料供重试，成功进入该任务审核中。当前提交与审核为原型适配器，不表示真实机构收到材料。

## 联系客服

客服抽屉展示本次姓名、采集项目和客服号，有号码时可复制，缺失显示未生成；这里的复制能力不恢复主卡已移除的复制入口。客服号帮助定位记录，不替代身份校验或授予查看别人任务的权限。

姓名、资格、名册等问题统一由知拍客服受理，再协调机构。咨询不创建新任务，不改变状态或付款事实；没有客服号也可以说明项目与问题。

## 邮件联系

客服入口继续打开邮箱联系抽屉，当前展示`zpai_service@163.com`，确认「打开邮箱」才外跳，取消保留原任务。打开或返回邮件应用不能提示已发送、已受理。

已确认目标为服务中心与任务共享「联系知拍客服」抽屉，提供复制邮箱、有效项目／客服号及打开失败恢复；正常业务仍为现有邮箱确认，完整共享结构与后台配置待补齐。正文预填细节尚需核对，不预填完整证件号或照片。
