# 编辑收货地址

用于新增或修改配送地址，返回后继续同一次冲印确认。照片与版式不属于本页可修改内容。

## 收货信息

冲印、明信片与邮票共用同一收货地址表单及校验，不各建字段。填写收件人、手机号码、省市区、详细地址，邮政编码可选。已有地址读取原字段后编辑，不能把占位文字存成真实地址。

## 默认地址与保存

可设置默认地址；保存新的默认地址时取消其他地址的默认标记，不能保留多个默认。保存成功后按当前流程选中地址并返回，按钮提交期间防重复；默认状态和当前选中属于不同事实。

## 表单校验

收件人非空且最多30字；手机号为以1开头、第二位3—9的11位号码；省市区至少4字、详细地址至少5字，邮编为6位数字或留空。必填或格式错误就近说明，输入统一去首尾空白。保存失败保留已填内容，明确地址未保存并允许重试。

## 返回与取消

顶部回地址列表或记录的来源；取消不提交半成品地址，也不删除原地址。不能因地址保存失败重建照片、排版或收费订单。
