# 设置密码

页面地址：`/?page=account&account=set`。已登录且尚未设置密码的用户从账号安全「登录密码」进入，为当前手机号增加密码登录方式。未登录回登录入口；该账号已有密码时转修改密码，不能用设置入口绕过原密码校验。

## 返回与当前账号

顶部返回账号安全，正文标题「设置密码」，说明「密码为8–32位，须包含字母和数字」，下方展示当前会话的脱敏手机号。该提示说明操作对象，不代表重新发过短信，也不允许直接在本页换绑定手机号。

退出本页不改变现有登录方式、订单、照片或任务。沿用账号任务表单与知拍按钮规范，真实键盘和大字体下输入及主操作仍需端上验收。

## 两次密码输入

依次填写「新密码」「确认新密码」，使用新密码输入语义，最多32位，眼睛按钮切换显示／隐藏。此页正常不出现原密码输入，因为前提是当前账号未设置密码。

保存要求8—32位且包含字母和数字，错误文案「密码须为8–32位，包含字母和数字」；确认不一致为「两次输入的密码不一致」。输入非空只满足按钮基础条件，仍需提交校验；失败保留内容供修正，不写入半个结果。

## 完成设置

主操作「完成设置」，处理中显示「保存中…」，禁止重复请求。成功为当前会话手机号生成新盐与摘要、清空表单，回账号安全显示「密码设置完成」，登录密码行转为已设置／修改。

成功不退出当前会话，不替用户新建业务或收费。存储／操作失败保留可恢复状态并允许重试；会话失效或离开后的迟到结果不能写入另一账号。设置入口若发现已有密码须按修改规则校验，不能覆盖。

## 协议与授权

本页没有独立协议复选框或第三方授权按钮，沿用当前已登录账号权限。需要阅读协议从隐私协议入口查看；不把本段文字写成当前表单可点击入口，也不擅自自动记录新的同意。

当前密码只以本地盐和摘要保存，不是明文，账号和会话在当前浏览器范围；真实服务端凭据、会话失效和正式安全流程尚未接入。本页没有发送真实短信。

## 设置后的登录与找回

完成后用户日后可从手机号主入口进入密码登录，仍需手机号、密码和同次协议同意。忘记密码时走绑定手机号验证码重置，重置完成须重新登录；不能把本页设置成功当作其他号码可用的验证授权。
