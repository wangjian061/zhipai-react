# 分类采集项目

页面地址：`/?page=collection&view=projects&category=enrollment`，毕业生、行业协会使用各自类别参数。从专项首页点击分类进入。本页只负责在选定类别内查找项目，随后进入项目详情；全部项目搜索使用独立页面，不沿用本页主题头图。

## 分类主题头部

头部展示当前类别名称、分类说明和对应插画：新生入学使用校园主题，毕业生使用学位帽，行业协会使用机构主题。返回按钮回专项列表，保留专区状态。没有专区底部菜单，不能在分类内部误认为已经进入本人记录。

标题和插画表达项目类别，不表示当前用户身份、采集资格或审核结果。直接地址进入关闭的类别同样受到入口配置限制，不通过参数绕过暂停入口。

## 本类项目搜索

搜索框显示「请输入搜索内容」，支持按当前类别的项目名称或机构名称查找。输入后点击「搜索」更新本类列表，清空后恢复本类项目；不会因清空跳到全部项目，也不会把其他类别的同名项目混入。

搜索只筛选项目，不验证身份、不查询学籍名册，也不按本人任务数量过滤。未登录仍可查找；个人记录读取异常不应阻断公开项目内容。需要跨类别搜索时，返回专项首页，从全部搜索入口进入。

## 采集项目与数量

列表标题为「采集项目」，旁边显示本次范围内的项目数量。每条包含项目图、完整名称、机构、采集时间与状态。长名称和机构允许换行，条目自然增高，不省略关键辨识信息；只有项目列表滚动，末项可完整查看。

点击任意条目进入该项目详情并记录类别、已提交关键词和位置。详情返回恢复原列表，不重置到全部项目，也不自动打开键盘。机构配图是示例环境素材，不代表已有真实机构授权。

## 项目状态与空结果

「未开始、进行中、已结束」由项目配置提供，均允许查看详情与既有记录。只有进行中且入口开放时可发起认证、拍摄或提交；列表命中不能解除该限制。

没有匹配条目时展示空列表说明，保留当前类别和关键词，用户可修改或清空后再次搜索。空结果与公开项目数据读取失败是不同情况，不用其他类别的项目填充空白。当前数据来自本地示例配置，没有远程搜索、搜索历史、热搜或推荐服务。
