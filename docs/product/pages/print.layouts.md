# 冲印照片 · 选择排版

照片已通过比例校验或已手动裁剪。第二步只选实体产品的排版，不再更换照片。

## 排版选择

仅“4大8小”和“8大”。大为二寸，小为一寸；4大8小是二寸4张加一寸8张，8大是二寸8张。每单一版，不加印、不选份数、不提供其他版式。

## 排版预览

两种横向排版预览使用本次真实候选或裁剪后的草稿照片。背胶模切、免剪裁、自带胶的产品规则一致；缩略图与主预览不能用旧示例照片替代本次裁剪结果。

## 读取与异常

加载失败显示暂时没有可用排版并提供重新获取；没有有效照片或排版不能继续。返回不丢当前有效照片和已选排版。

## 上一步与下一步

底部上一步回选照片，需要换图在那里进行；下一步进入确认订单。顶部返回退出冲印到来源，不切换内部步骤。
