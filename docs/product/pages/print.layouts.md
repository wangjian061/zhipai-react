# 冲印照片 · 商品展示与冲印预览页

2026-11-20 按实物照片商品范式重构（样式、结构与明信片、纪念邮折保持一致）：顶部主图舞台配合下方多图横向缩略条自由浏览多张商品实拍与成品效果，版式作为类似电商详情页的规格选项内嵌于商品信息白卡中（不再独立块状外置），选图后在「冲印预览」上滑抽屉内同屏完成整版成品预览与手动 5∶7 裁剪。保留原确认订单、地址与付款。

## 商品展示、多图画廊与内嵌版式选择（与明信片样式一致）

- **主图展示与多图缩略条**：复用圆角舞台（`.keepsake-product-stage`）和横向缩略条（`.keepsake-choice-rail`）。主图舞台固定为 `3∶2`，铺满四张商品图。混排整版、二寸8张、斜角实拍与模切细节均来自真实产品照片，统一为 1200 × 800 px、浅冷灰背景与柔和光影。知拍标识和普通说明文字保留原图细节，订单号和二维码作局部遮盖。照片排版、人像和模切线保留实拍细节。点主图打开深色大图查看层，上一张、下一张切换后关闭时保留当前商品图。选图、裁剪或在冲印预览抽屉内更换版式，返回时保留原来的商品图。用户照片的整版预览在抽屉与确认订单中展示。
- **版式作为淘宝风产品规格内嵌商品白卡**：取消页面中部独立分离的版式切换块。唯一商品信息白卡（`.keepsake-product-spec`）沿用同款标题和简介（「自带背胶 · 免剪裁，下单前可预览并手动裁剪构图」）；细分隔线后首行即为淘宝风 **`版式`** SKU 规格芯片行（并排紧凑胶囊：`二寸4张＋一寸8张` / `二寸8张`，在商品页点选联动对应整版商品图与下单版式），下方紧跟 `相纸规格：富士相纸 六寸`、`相纸工艺：背胶模切` 与 `购买限制：每单 1 版，不支持加印`。冲印费和运费在确认订单页展示。

## 照片来源

点击商品页底栏「上传照片 · 预览效果」或抽屉内「换一张」打开共用选图抽屉，支持知拍相册与手机相册、单选；手机输入为30MB以内的JPG、PNG、WebP。取消或读取失败保留原照片、版式和裁剪构图；换新图清除旧裁剪缓存并用新图刷新预览，不覆盖相册原图。

## 冲印预览

确认选图后自动拉起公共上滑抽屉「冲印预览」（任意比例照片先按默认 5∶7 居中自动适配，保证整版预览即刻可见）：
- **分段切换 `整版成品 | 手动裁剪`**：默认展示「整版成品」，在 `#F5F7FB` 展台内大面积预览嵌好照片的整版相纸成品（含底栏印记与浅投影；重新生成预览期间保留上一帧已就绪整版，不回退闪烁灰格），下方可用小巧轻标签切换「二寸4张＋一寸8张 / 二寸8张」实时对比；切至「手动裁剪」时展示清晰的一寸 5∶7 裁剪框，与下方三行滑杆「缩放 / 水平 / 垂直」保持 `12px` 间距，支持拖动、双指缩放、桌面滚轮与紧凑右对齐「复位」手动微调构图，切回「整版成品」立刻刷新整版预览。
- 任意比例照片均可手动微调构图；生成最终裁剪文件后，两种排版与后续订单均读取该校验后的裁剪文件。

## 底部操作

- **商品页底栏**：未选图展示常亮主按钮「上传照片 · 预览效果」；已选图关闭预览返回商品页时，底栏展示「继续预览」+「去确认订单」。
- **预览抽屉底栏**：左次按钮「换一张」，右主按钮「满意，去确认订单」。有效照片、合格 5∶7 裁剪产物、排版及资源就绪后进入[确认订单页](print.confirm.md#费用与支付)。

## 读取、返回与付款保护

首次生成时显示斜向微光骨架和「正在生成冲印预览…」。重新生成时保留上一次完成的整版，最新裁剪与排版就绪后一起更新。点击进入确认订单会等待最新裁剪文件通过校验。失败可原位重试或换图。浏览器返回先关闭预览，保留构图与选择。顶部返回完整来源，带图入口恢复照片详情或个人中心照片抽屉。已付或付款未知按原单恢复；未知先查原单，不允许替代建单。确认页「上一步」恢复发起确认的商品页或预览抽屉仍保留照片、排版、裁剪与地址。
