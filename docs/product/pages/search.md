# 照片工具搜索

页面地址：`/?page=search`。由知拍首页搜索入口进入，用关键词查找证照规格、照片工具或冲印服务，选择后进入相应业务。它不搜索学校、机构采集项目；查项目须进入专项专区使用项目搜索。

## 返回与搜索输入

顶部固定返回与输入框，提示「搜索证照规格、照片工具」，右侧「搜索」。返回回知拍首页。输入最多60字符，进入时聚焦，支持键盘搜索与点击按钮；从带q参数地址进入会带入并匹配。

正在编辑会清除旧结果状态，点击搜索后才显示本次匹配，不让输入与旧结果看似对应。提交去首尾空白，匹配时忽略大小写及空白；地址替换当前查询，不增加每个关键词一条返回历史。

## 查找你需要的照片工具

初始或关键词为空时显示搜索图标、「查找你需要的照片工具」「输入证照规格或工具名称」。不提前铺热门或全部业务，不增加搜索历史、热搜、远程请求或推荐。

这是本地功能目录匹配，不查个人照片内容、订单、身份信息或机构名册；未登录可以使用，选择需要登录的后续业务时再按原流程处理。

## 搜索结果

有结果显示「搜索结果」及项数，下方一行一个名称与箭头，整行进入对应功能。目录包含一寸证件照、两寸证件照、简历照片、会员照片、冲印服务、照片精修、照片换装、证照规格、照片裁剪、更换背景、格式转换和修改体积，并支持相关别名。

| 匹配的入口 | 点击后的实际首步 |
| --- | --- |
| 一寸／两寸／简历／会员／证照规格 | 进入同一九项规格目录，不按搜索词自动选定规格 |
| 冲印服务 | 进入选照片，后续比例校验、排版、地址和付款由冲印页处理 |
| 精修／换装／裁剪／换背景／格式／体积 | 进入对应工具选照片，选后停第一步，点下一步才检查或设置 |

进入目标携带当前搜索页作为来源，工具顶部返回按来源恢复；不在搜索结果先弹选图或直接制作。独立精修为¥2.00，与个人制作精修版¥9.80是不同业务，结果行本身不产生购买权益。

## 没有找到相关结果

无匹配显示「没有找到相关结果」「换个关键词试试，例如“一寸”或“换背景”」，保留关键词供改写。清空输入恢复初始态，不把没有匹配当服务故障，也不自动进入最接近的工具。

当前只做本地目录，不人为显示网络失败；别名不等于能处理任意需求。例如搜索会员照片进入个人规格目录，不自动进入协会采集或获得项目资格。

## 目标工具的来源和能力

搜索只交接入口，选图、取消、收费、检查失败与结果保存仍由各工具承担。换装仅知拍相册为已确认待实施限制，当前旧代码手机来源差异不能因搜索入口继续存在就忽略；其他工具沿用各自有效来源。

搜索不会把宣传图或上一张照片带入新流程，也不替用户购买、下载或提交。依据：[首页契约](../home-1.4.6.md)、[规格契约](../photo-specifications-1.4.6.md)、[搜索目录与路由](../../../src/domain/app.js)、[搜索页面](../../../src/pages/SearchPage.jsx)。本页内容核对不代表实际键盘、视觉或后续真实处理服务验收。
