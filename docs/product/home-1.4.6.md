沉浸式图片从屏幕顶端开始，在图内保留连续浅蓝灰安静背景以容纳灵动岛、时间、信号、Wi-Fi及电量；按用户要求直接裁掉原图顶部48px源像素，人物与文字像素不变，减少多余空白。页面没有顶部padding、额外占高、独立空白条，也不在图片中绘制系统UI。轮播框1612∶928，图片contain完整等比展示，宽高属性采用各文件实际尺寸；当前402×874预览中轮播约231px高，业务点击区避开62px状态区。主内容margin-top为0，不能负向叠压遮挡图片下沿；系统外壳保持既有实现。

专项横幅以三种形象区分人群：新生持入学通知、毕业生着学位服并戴学位帽、协会人员穿专业服装并配无机构标识工作证。所有人物均为生成的宣传示意，不代表真实用户或机构，不作为实际采集合规照片示例。

主内容左右16px留白、顶部20px，搜索到专项及专项到工具各20px。专项与工具白卡均20px圆角、极轻阴影；两处区块标题使用同一左对齐线、16px／650／24px。搜索下方专项主卡组件、配图、文案与样式完整保留：内边距上20px、左右16px、下16px，人群说明与标题间4px、与配图间12px；原无字配图3∶1、contain完整展示，标题与人群由页面渲染。窄空间及字体放大时允许主卡人群自然换行，不能截断或缩小字号。

工具卡四周内边距统一16px，标题到网格16px。网格四列两行、零间隙，1px极淡蓝灰线`#F1F4F8`及同色外框，外框12px圆角；左右外边线与专项主卡配图对齐。32px图标容器内使用24px图形，图文间6px，每格最小76px高、上下8px内留白、居中排列；长文字可增高，按压不缩放网格，键盘焦点轮廓在格内显示。工具卡须在标准首屏完整展示，底部与菜单保持净距，当前402×874源码几何推导约19px；字号或内容增大时仍可增高并自然滚动。工具名13px／500／20px、颜色`#4F5F76`；四个免费角标16×12px、9px字、无描边。内容末尾预留56px导航高度＋实际底部偏移＋40px净距，正文底色保持`#F3F5FC`；导航后方承托层无侵入时完全透明，内容实际越过菜单顶边才随侵入深度渐显，24逻辑像素时为完整强度。渐变从底部较实的同色背景向上渐透明，顶部延伸32px，底部延至安全区；其余色值沿用DESIGN最新首页章节。

## 二、入口、输入与输出

首页不要求照片、任务、项目或订单标识。进入各业务时由目标流程建立自己的上下文；工具、冲印、相机与扫码记录当前首页地址作为返回来源，不传入示意图或虚构照片数据。

| 首页动作 | 输入与当前输出 | 返回及边界 |
| --- | --- | --- |
| 点击搜索入口 | `go("search")`，进入`/?page=search`，首页不提交关键词 | 搜索页顶部返回首页；搜索结果、空态与完整状态契约仍待单独整理 |
| 点击专项主卡任意区域 | 单一链接`/?page=collection`，普通主键点击调用`go("collection")`；不预选项目或人群分类 | 具体项目在专区选择，规则见[专项采集说明](../collection-zone.md)；主卡箭头不是第二个按钮 |
| 冲印服务 | `openPrint()`，不带照片，进入冲印选图 | 来源为首页，后续裁剪、排版、付款与返回见[工具与冲印契约](common-tools-1.4.6.md) |
| 照片精修／照片换装／照片裁剪／更换背景／格式转换／修改体积 | 分别为`repair`／`outfit`／`crop`／`background`／`format`／`resize`，直接进入对应选图阶段 | 共用选图组件，来源按工具限制；换装仅知拍相册、手机相册禁用（2026-10-22确认，待代码实施），其他工具支持两种相册。保留首页返回地址；检查、成功、失败与结果去向见[工具契约](common-tools-1.4.6.md) |
| 证照规格 | `openPhotoTool("spec")`，进入`/?page=specifications`并携带当前地址为返回来源；搜索中的规格结果也进入同一目录，不自动选中规格 | 三列九项，选择后在抽屉选底色，再去拍照或选图；参数带入现有制作页并可编辑。返回恢复来源，完整交接与取值边界见[规格契约](photo-specifications-1.4.6.md) |
| 顶部专项图／「进入专区」 | `go("collection")`进入专项专区 | 不预选项目或人群；项目选择、认证、付款在专区进行 |
| 顶部制作图／「开始制作」 | `openCamera()`进入既有拍摄／选图流程 | 保存当前首页完整地址为`returnTo`；取消、权限、选图、确认及结果返回沿用[制作契约](camera-confirmation-1.4.6.md)，不传入宣传图作为制作照片 |
| 顶部精修图／「开始精修」 | `openPhotoTool("repair")`进入精修选图 | 保存首页`returnTo`；照片检查、付款、处理、结果及恢复沿用[工具契约](common-tools-1.4.6.md) |
| 底部首页／相册／我的 | 分别`go("home")`／`go("album")`／`go("my")` | 不附加照片或订单标识；首页按钮显示当前页状态 |
| 相机／扫码 | 分别`openCamera()`／`openCamera("scan")`，进入相机或扫码并记录首页返回地址 | 权限、取消、拍摄制作与恢复见[制作契约](camera-confirmation-1.4.6.md)；不能将打开入口视为已获得系统权限 |

## 三、交互与状态

- 专项卡是一个原生链接，以扩展点击区覆盖整卡；保留链接地址及修饰键／非主键的浏览器行为。键盘聚焦在整卡显示知拍蓝轮廓，按压卡片轻微缩放；不增加独立图片按钮或自动动效。
- 主卡链接名称为「进入专项采集」，适用人群作为关联描述。图片使用空alt，箭头对辅助技术隐藏，避免重复朗读装饰内容；真实读屏效果尚未验收。
- 顶部轮播每7秒自动切换，支持左右滑动及键盘方向键。页面隐藏、离开首页、图像不可见、鼠标悬停、键盘焦点、滑动中、打开选图层或减少动态效果时暂停；新图加载成功后才切换，失败保留当前图，过期加载不能覆盖后一次选择。滑动结束不误触业务跳转。
- 当前横幅以一个透明按钮进入对应业务，按钮可访问名称重复完整标题、说明及动作；图片使用空alt，非当前幻灯片隐藏并设为inert。正常状态没有叠加可见文字；当前图片加载失败时显示业务标题、「图片暂时无法显示」与对应操作文字，仍能进入同一业务。图内字不会随系统字号单独放大，读屏与小屏可读性仍需实际验收。
- 首页内容自然纵向滚动，末尾净距使最后一行能完整移至菜单上方，导航后方承托层只在实际重叠时显示下实上透的渐变，内容退出菜单区、离开首页或测量引用缺失时恢复透明。不存在专项主卡加载任务、认证、付款或项目结果状态；这些状态由目标流程承担。专项主卡装饰图加载失败时标题、适用人群与链接仍独立存在，主卡仍无专用图片失败占位。
