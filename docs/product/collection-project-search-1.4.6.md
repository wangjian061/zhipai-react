# 知拍1.4.6 · 专项项目搜索

更新：2026-10-26。已按[确认结构图](../reviews/collection-project-search-20261026/approved-structure.png)实施，待用户实际页面验收。源码、状态及静态渲染验证不代表真机视觉验收；本轮登记原型版本 `10.26-1`，提交／推送基线以[交付台账](../releases/prototype-deliveries.md)及远端标签为准，本次不部署站点。

## 范围和职责

仅调整 `/?page=collection&view=projects&category=all` 的全部项目搜索。新生入学、毕业生、行业协会分类列表保持原头图、项目列表及范围内搜索。项目详情、机构／个人码认证和后续采集流程不在本轮重做。

用户按项目名称或机构名称查找项目，点击结果进入原项目详情。当前数据仍来自本地示例项目；没有新增远程搜索接口、历史搜索、热搜或推荐功能。

## 页面结构

系统顶部安全区 → 固定「返回＋搜索框＋搜索」→ 独立滚动正文。移除全部搜索页的大幅主题头图，不显示专区底部菜单，不增加页面标题占高。可访问标题为「项目搜索」。

| 状态 | 呈现与操作 |
| --- | --- |
| 未输入／空白查询 | 「查找采集项目」「输入项目名称或机构名称」；不展示全部项目或“搜索结果”数量 |
| 已搜索且有结果 | 「搜索结果」及项目数，随后为项目条目；保留名称、机构、采集时间和项目状态 |
| 已搜索且无结果 | 「未找到相关采集项目」「请检查名称，或换个关键词试试」；保留关键词，「修改关键词」聚焦并选中原输入 |

搜索框支持清空、按钮搜索与系统键盘搜索，最多输入60个字符，提交时移除首尾空白。输入非空文字仅修改候选关键词，点击搜索或键盘搜索才更新结果；点击清空或删除至空值恢复初始态。搜索成功提交后收起输入键盘，不人为增加网络等待。相同关键词再次搜索将结果回到顶部，不增加重复历史记录。

## 进入、返回和状态保护

1. 专区入口已经输入关键词时，搜索页带入并直接展示对应结果。直接进入不带关键词的地址则显示初始态。
2. 点击顶部返回回专项列表，保留原专区位置和其他栏目状态。
3. 点击结果进入原项目详情，携带搜索来源、类别和已提交关键词；返回时恢复结果、滚动位置及源项目焦点，不自动聚焦输入框或弹出键盘。
4. 全部搜索页内更新／清空关键词替换当前搜索地址，不让系统返回逐条遍历关键词历史。不同关键词使用独立滚动记录；明确发起新搜索时结果从顶部开始。
5. 项目开放、认证方式及开始采集权限仍由原项目规则控制，搜索命中不代表允许开始采集。未开始和结束项目仍可查看详情。
6. 全部项目搜索不依赖用户个人采集记录加载成功，未登录也可搜索。个人记录的加载／错误信息不混入搜索正文；其他业务原有读取错误与恢复动作保留。

## 视觉及三端还原

- Operate模式，沿用知拍浅蓝白、深蓝文字与知拍蓝操作，不引入新品牌、插画或订单磨砂材质。主画布使用 `--ui-canvas`。
- 外层专项页在 projects 视图不提供顶部安全区，独立搜索组件仅承担一次真实／预览安全区；头部不参与正文滚动。原生端按实际安全区与键盘可用高度适配，不复制62px硬编码。
- 返回44×44px白色圆底、20px深蓝箭头；搜索输入与操作触控至少44px。输入14px，按钮14px，结果区标题16px，项目名14px，辅助及状态12px，空态标题18px、说明14px；左右正文16px，顶部搜索栏与正文间24px。
- 结果复用既有项目条目及项目状态，本页使用16px白卡、无额外阴影，56×72px项目图，保留既有机构图片；长标题／机构及时间允许自然增高。搜索辅助色沿用现有搜索的 `#657181`；项目语义色沿用原集合状态，不将付款／审核语义移入项目状态。
- 只有正文滚动，底部留出系统区域与24px内容间距，末项可达。按钮保留可见焦点及44px触控，清空使用现有关闭图形，结果数量由轻量状态区播报；减少动态效果时禁用按钮过渡。
- 当前为React Web原型，项目仍用示例配置。实际手机键盘、输入法、小屏、大字、系统返回和读屏由用户及三端研发继续验收。
