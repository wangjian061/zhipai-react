# 账号登录 · V1.4.6产品契约

更新：2026-11-03。状态：用户已确认A结构并完成本地实现，第二阶段补齐密码重置单屏样式，待用户验收。本文件对应React移动Web原型；iOS、Android、鸿蒙按同一业务流程还原，原生工程和正式认证服务尚未接入。完整范围见[第二阶段需求](collection-stage2-1.4.6.md)；此次本地扩展未提交／推送，11.3-1仅为输入基线。

## 背景与确认依据

登录服务于个人中心及被登录拦截的原业务：在同一手机号入口内兼顾首次与回访用户，通过验证码完成登录；密码为次入口，平台第三方方式置底。移除运营商一键登录及其专用服务协议，沿用既有知拍设计。

用户已在2026-11-02展示的三方案中选择A，并确认历史号码、验证码及密码关联状态。[A主入口结构](../reviews/account-login-20261102/approved-structure.svg)和[关联状态结构](../reviews/account-login-20261102/approved-states.svg)是已确认样图的原样归档，属于结构参考，不是实际页面截图或最终视觉批准。[DESIGN账号规范](../../DESIGN.md#账号登录2026-11-02)记录当前布局及组件值。

## 入口、主流程与返回

1. 个人中心「登录 / 注册」、未登录账号安全入口及原业务登录拦截进入同一流程。兼容原 `account=welcome`／`phone` 链接，均直接显示手机号任务，不再经过欢迎层。
2. 输入有效11位大陆手机号，或使用脱敏的上次成功号码；明确同意《用户协议》和《隐私政策》后点击「获取验证码」。未注册号码验证后自动建立本地账号。
3. 进入「输入验证码」，输入六位验证码，点击「登录」；验证通过后回原同源业务。登录完成不替原业务付款、提交照片或再次创建采集任务。
4. 验证码页返回号码步骤并保留号码及同意选择；密码页返回主入口；找回／重置返回密码入口。主入口返回取消登录，回原来源。弹层打开时返回先关闭弹层。
5. 返回目标仅接受同源且非账号页的地址；缺失、非法、外部地址或循环目标回 `/?page=my`。有效本地会话进入主登录入口时直接返回原来源，无需再次展示登录。
6. 扫码登录后的内存交接及取消行为继续以[扫码采集契约](scan-collection-1.4.6.md)为准，不由账号模块延长时效或重建业务记录。

## 页面与操作

各页自上而下沿用圆形返回、品牌行、任务标题、说明、表单和操作；无外包欢迎卡。手机号、验证码、密码、绑定、找回及重置页均须在手机可用高度内完整呈现，不允许页面或表单滑动；保留已确认A的区块顺序，收紧留白时仍须使当前输入和主操作在键盘打开后可达。2026-11-03重置页接入同一入口单屏样式，主登录布局保持。

本地实现已在上述登录范围禁用正文滚动与过度滚动，以固定可用高度及收紧留白保留原内容、字号和触控尺寸。当前设备预览为402×874逻辑屏幕、62px状态区和34pxHome区，沿用整体缩放；没有新增真实软键盘高度适配。此处记录实现与要求，不能据源码估算宣称所有机型、键盘及大字体都已完整可见。

| 页面／状态 | 内容及主次操作 | 成功、失败与下一步 |
| --- | --- | --- |
| 手机号主入口 | 「手机号登录」「未注册的手机号验证后将自动注册」；手机号输入；协议；主按钮「获取验证码」；文字「密码登录」；底部「其他登录方式」 | 号码有效且同意后可发送；缺失或不合法显示「请输入有效的11位手机号」，未同意显示「请阅读并同意用户协议和隐私政策」；成功进入验证码页 |

| 验证码 | 「输入验证码」；已发送至脱敏号码的说明；「6位验证码」；错误／演示提示；重发倒计时；主按钮「登录」；「更换手机号」 | 六位后可提交；错误「验证码不正确，请重新输入」，过期「验证码已过期，请重新获取」。更换号码清除旧验证状态，重发成功清空旧输入；本页不展示第三方入口 |
| 密码登录 | 「密码登录」「使用手机号和已设置的密码登录」；手机号及密码输入、显示／隐藏密码、「忘记密码」、协议；主按钮「登录」；「验证码登录」；底部平台方式 | 新一次提交清除旧重置成功提示，再展示本次结果；错误「手机号或密码不正确」；未设密码「该手机号尚未设置密码，请使用验证码登录」。成功回原业务；切换方式保留号码与同意选择，密码输入清空 |

## 状态、输入与记住号码

| 规则 | 当前原型行为 |
| --- | --- |
| 短信挑战 | 与当前手机号、用途（登录／绑定／重置）及第三方上下文对应；验证码5分钟有效，60秒后允许重发。同一挑战冷却期内返回再获取仍使用原挑战，不重置有效期 |
| 更换号码 | 清除验证码、挑战、倒计时、错误、提示及重置手机号验证授权；返回与用途对应的号码步骤。号码不能沿用另一号码的验证结果 |
| 防重复与迟到结果 | 忙碌时禁用相关提交和返回；离开流程清除临时数据并使旧异步结果失效。操作失败保留可恢复输入，提示「操作未完成，填写内容已保留，请重试。」 |
| 成功历史 | 只在短信、密码或第三方绑定后的登录真正成功时记录号码；最新成功覆盖旧号码。读取历史时校验号码格式与本地账号存在性，不从账号列表顺序猜测上次用户 |
| 退出与注销 | 普通退出删除会话，保留成功号码；注销删除本地账号并清除与该账号匹配的记住号码。重新进入仍需验证；记住号码从不代表有效登录 |
| 协议选择 | 每次新登录流程初始为未勾选，记住号码不自动同意；同一次流程查看协议、返回或切换登录方式保留选择。离开账号流程清除；发送验证码、密码登录和发起第三方授权均校验同意 |
| 焦点及可访问性 | 验证码使用单一输入承载粘贴与系统验证码，进入时聚焦；错误使用alert、提示使用status。弹层使底页inert并约束焦点，关闭恢复原入口；样式含可见焦点及减少动态效果支持，实际读屏与键盘仍待验收 |

当前短信固定显示「原型演示验证码：123456」，不发送真实短信；第三方抽屉模拟授权，不调用平台SDK。协议正文为演示内容，账号、会话及最后成功号码保存在当前浏览器本地，跨域名、端口或设备不共享。密码仅存本地盐与摘要，不存明文；这不代表已经完成正式认证与安全接入。

正式产品仍需接入短信发送／校验、第三方SDK与服务端凭据校验、账号归属及绑定、会话签发／失效、找回／注销服务、正式协议正文及记录。三端使用真实平台和系统返回、安全区、键盘与生命周期能力，不把浏览器识别或本地手机号会话当作正式认证。此处列接入缺口，不把未定接口地址、版本或发布结果写成已有能力。
