## 业务流程与页面职责

首页「证照规格」／搜索中的规格入口 → 证照规格页 → 点击规格 → 选择背景颜色抽屉 → 「去拍照或选图」 → 相机拍照或手机相册选图 → 现有「证件照制作」页 → 检测及制作 → 只读结果。

搜索中的「一寸证件照／两寸证件照／简历照片／会员照片／证照规格」均进入该目录，不自动选规格；用户在列表点选本次用途。首页入口与返回契约见[首页文档](home-1.4.6.md)。

| 从上到下 | 确定内容 | 点击及状态 |
| --- | --- | --- |

### 资料出处与取值边界

- 求职招聘：用户于2026-10-20确认采用二寸，413×579px、35×49mm，蓝／白／红；这是产品默认预设，不表述为招聘行业通用标准。
- 普通四项：沿用本项目已确认预设；不将毫米×300dpi的近似整数换算宣称为外部认证标准。
- 四六级：[河南师范大学2026年下半年报名通知](https://www.htu.edu.cn/teaching/2026/0914/c14835a404146/page.htm)附件为144×192、JPG、不超过200KB、浅蓝底。本原型采用现有蓝色作底色示意，**没有新增考试文件大小校验、专用色值或真实合规识别**；不能据此承诺全国各考点通用或通过审核。
- 驾驶证：[北京市公安交管办理材料](https://www.beijing.gov.cn/fuwu/bmfw/bmzt/jsz/bl/201908/t20190820_1845196.html)为白底、22×32mm；260×378px为本产品按300dpi取整的输出预设，不是该页面规定的像素值。
- 身份证：[南昌市公安局2025年采集相片参数](https://ncga.nc.gov.cn/ncgaj/zfcg/202511/6adf48f0bf574285928637bbffa94fb5.shtml)为358×441px、350dpi、26×32mm、白底。本原型没有承诺受理自带照片、照片回执、350dpi元数据或14–20KB合规输出。
- 中国护照：[国家移民管理局全程网办照片指引](https://s.nia.gov.cn/mps/bszy/qcwbzpzy/zpzy/202405/t20240528_1001.html)说明3∶4、宽400–1000px；本产品在该范围选择600×800px、白底。此项特指**全程网办电子照片**，不冒称33×48mm纸质护照照片，未接入护照审核及回执服务。

资料核对日期2026-10-20。实际申请应以对应受理方要求为准。项目现有精修、抠图、制作模拟不等于法定证件真实性或官方受理能力。

## 选色抽屉

1. 只在点击有效规格后打开，背景页面不可操作，关闭、空白遮罩、Escape及系统返回均关闭抽屉。
2. 固定标题「选择背景颜色」，右侧44px关闭区。正文展示选中用途及实际输出规格，如「驾驶证」「22 × 32 mm · 260 × 378 px」。
3. 「背景颜色」下展示对应可选色，圆形色块、颜色名称和选中勾，不能只靠颜色区分；选中态蓝色外圈。颜色顺序取当前规格配置；原色有效保留，唯一有效颜色自动选定，多色且原色失效时清空待选；不按寸照或用途名称写死条件。
4. 有效多色说明「拍摄后仍可在制作页调整规格与底色。」；待选说明「请为当前规格选择背景颜色。」；单色说明「该规格仅支持{颜色名}背景，已自动选定。」。无有效颜色显示「当前规格的背景颜色暂不可用，请选择其他规格或稍后再试。」，不显示备用色。
5. 固定底栏「去拍照或选图」，有有效选择才可点击；确认再次按当前配置校验。只有正文可滚动，按钮预留系统底部区域。确认立即进入相机，交接键盘焦点并替换抽屉的历史记录，防止返回时再次弹出。
6. 关闭不创建草稿、不付费、不跳相机；返回列表保留选中项和滚动位置。刷新或浏览器前进只回列表，不自动重开抽屉；清除旧抽屉历史标记，避免再次关闭无效。键盘焦点限制在抽屉内，关闭恢复触发位置。

## 参数交接、返回与异常

| 上一步 → 下一步 | 确定行为 |
| --- | --- |
| 选色 → 相机 | 传递规格稳定ID与背景色；URL仅携带已知目录参数及本地返回地址，不接受自定义数值 |
| 相机首拍／手机相册 → 制作 | 新草稿取所选规格的宽高及底色；名称保留用途身份，不因像素或比例相同而降为泛称；不能覆盖成默认二寸蓝底 |
| 制作内修改 → 重新拍摄／重新选择 | 保留最新规格与底色；取消设备选图保留原照片和参数；选图完成替换原图，清除旧检测和制作结果 |
| 刷新 | 相机页从已验证的目录参数恢复待拍设置；制作页从本地草稿恢复原图、规格及底色 |
| 相机或制作页顶部返回 | 退出本次制作，回规格列表，不在相机与制作页循环；重新拍摄中的返回只取消本次重拍并回原制作页 |
| 开始制作 | 沿用现有原型演示场景、检测抽屉、制作Loading及结果弹窗；**不新增规格或底色二次确认** |
| 未解锁结果返回 | 沿用丢弃结果确认，仅丢弃结果，保留原照片与参数，回制作前状态 |
| 已解锁结果返回 | 沿用先保存后退出及付款账号校验，不丢弃已付款照片 |
| 普通相机／专项采集 | 普通相机新进入尝试原默认并按当前配置校验；专项采集继续项目固定规格，不受个人规格入口残留参数影响 |
| 无效参数／旧入口 | 未知规格或颜色不创建自定义项；不合法返回地址回首页；旧 `page=tool&tool=spec` 归到新页 |

界面统一「照片规格／更多规格／选择规格／使用此规格／预设规格」。技术字段 `specId`、像素尺寸以及实体测量术语保持准确。
